# Spec 1.6 Validation — Data Dictionary, Quality & Seed Data

## Definition of Done

1. `npm run build` exit 0
2. `/dictionary` page hiển thị tất cả dictionary entries
3. Dictionary filter by dataset hoạt động
4. Dictionary search by column name hoạt động
5. Quality score auto-calculate khi tạo dataset
6. Quality score hiển thị trên listing cards (badge màu)
7. Quality score hiển thị trên detail sidebar
8. Seed script chạy thành công
9. ≥ 4 datasets hiển thị trên listing page
10. Tags vocabulary seeded (≥ 5 tags)
11. Data dictionary entries cho seeded datasets
12. Listing page browse được seeded datasets
13. Detail page hiển thị seeded data trong DataTable
