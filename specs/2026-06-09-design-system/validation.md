# Spec 1.2 Validation — Design System

## Definition of Done

1. `npm run build` exit 0
2. `<link>` Google Fonts trong `<head>` (view page source)
3. Source Sans 3 applied cho body text
4. IBM Plex Mono applied cho `.font-mono` elements
5. CSS custom properties `--hf-yellow`, `--hf-bg` etc. accessible trong `:root`
6. Không có CSS `@import` cho fonts
