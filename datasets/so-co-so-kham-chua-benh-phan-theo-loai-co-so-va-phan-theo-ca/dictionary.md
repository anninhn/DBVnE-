# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Loại cơ sở` | category | - | - | - | Phân loại cơ sở khám chữa bệnh, bao gồm tổng số và các loại hình cụ thể như bệnh viện, nhà hộ sinh, trạm y tế. |
