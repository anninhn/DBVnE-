# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Địa phương` | category | - | - | - | Tên địa phương (tỉnh/thành phố), vùng kinh tế hoặc cấp quốc gia (CẢ NƯỚC). |
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Ghi chú` | string | - | - | - | Ghi chú về dữ liệu, ví dụ 'Sơ bộ' cho dữ liệu chưa chính thức. Cột này thường để trống. |
| `Tỷ lệ dân số đô thị được cung cấp nước sạch qua hệ thống cấp nước tập trung` | number | - | - | % | Tỷ lệ phần trăm dân số khu vực đô thị được cung cấp nước sạch qua hệ thống cấp nước tập trung. |
