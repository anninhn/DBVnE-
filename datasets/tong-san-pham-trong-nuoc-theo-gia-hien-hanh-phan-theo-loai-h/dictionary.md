# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Chỉ tiêu` | category | - | - | - | Các chỉ tiêu phân loại tổng sản phẩm trong nước (GDP) theo thành phần kinh tế hoặc ngành kinh tế. |
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Ghi chú` | string | - | - | - | Ghi chú về trạng thái dữ liệu, ví dụ 'Sơ bộ' chỉ dữ liệu ước tính ban đầu. |
| `Giá trị (Tỷ đồng)` | number | , | . | tỷ VND | Tổng sản phẩm trong nước (GDP) theo giá hiện hành. |
| `Cơ cấu (%)` | number | , | . | % | Tỷ trọng của từng chỉ tiêu trong tổng sản phẩm trong nước (GDP). |
