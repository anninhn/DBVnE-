# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Khu vực` | category | - | - | - | Phân loại khu vực vận tải: Tổng số, Trong nước, hoặc Ngoài nước. |
| `Ghi chú` | string | - | - | - | Ghi chú về trạng thái dữ liệu (ví dụ: 'Sơ bộ' cho dữ liệu chưa chính thức). |
| `Khối lượng (Nghìn tấn)` | number | , | . | nghìn tấn | Tổng khối lượng hàng hóa được vận chuyển. |
| `Chỉ số phát triển (Năm trước = 100) (%)` | number | , | . | % | Chỉ số phát triển khối lượng hàng hóa vận chuyển so với năm trước (lấy năm trước làm gốc 100%). |
