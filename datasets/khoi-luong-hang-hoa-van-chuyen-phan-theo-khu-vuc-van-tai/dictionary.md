# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `chỉ số phát triển, Năm` | category | - | - | - | Phân loại khối lượng hàng hóa vận chuyển theo khu vực: Tổng số, Trong nước hoặc Ngoài nước. |
| `Ghi chú` | string | - | - | - | Ghi chú về dữ liệu, ví dụ 'Sơ bộ' cho dữ liệu chưa chính thức. Hầu hết các dòng đều trống. |
| `Khối lượng (Nghìn tấn)` | number | - | - | nghìn tấn | Tổng khối lượng hàng hóa được vận chuyển trong kỳ thống kê. |
| `Chỉ số phát triển (Năm trước = 100) (%)` | number | - | - | % | Chỉ số phát triển khối lượng hàng hóa vận chuyển so với năm trước, lấy năm trước làm 100%. |
