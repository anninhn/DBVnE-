# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Tỉnh, thành phố` | category | - | - | - | Tên tỉnh, thành phố hoặc vùng kinh tế có hoạt động khai thác cá biển. Bao gồm cả dữ liệu tổng hợp cho 'CẢ NƯỚC'. |
| `Năm` | number | - | - | năm | Năm thống kê sản lượng cá biển khai thác. |
| `Ghi chú` | string | - | - | - | Thông tin ghi chú về dữ liệu, ví dụ 'Sơ bộ' cho biết dữ liệu chưa phải cuối cùng. Cột này có nhiều giá trị rỗng. |
| `Sản lượng cá biển khai thác` | number | , | . | unknown | Tổng sản lượng cá biển được khai thác trong năm của từng địa phương hoặc vùng. |
