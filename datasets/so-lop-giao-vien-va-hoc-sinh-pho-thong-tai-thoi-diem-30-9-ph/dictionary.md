# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `chỉ số phát triển, Phân loại` | category | - | - | - | Chỉ số hoặc đối tượng được thống kê, bao gồm 'Lớp', 'Giáo viên' và 'Học sinh'. |
| `Cấp học` | category | - | - | - | Cấp học của các cơ sở giáo dục phổ thông, bao gồm 'Tổng số', 'Tiểu học', 'Trung học cơ sở' và 'Trung học phổ thông'. |
| `Năm học` | string | - | - | năm học | Năm học mà dữ liệu được thống kê (ví dụ: 2020-2021). |
| `Loại hình` | category | - | - | - | Loại hình trường học, bao gồm 'Công lập' và 'Ngoài công lập'. |
| `Ghi chú` | string | - | - | - | Ghi chú về tính chất của dữ liệu, ví dụ 'Sơ bộ'. Cột này có nhiều giá trị trống. |
| `Số lớp, giáo viên và học sinh` | number | , | . | unknown | Số lượng lớp học, giáo viên hoặc học sinh tương ứng với các tiêu chí phân loại. |
| `Chỉ số phát triển (Năm trước = 100) (%)` | number | , | . | % | Chỉ số phát triển của số lớp, giáo viên hoặc học sinh so với năm học trước (lấy năm trước làm 100%). |
