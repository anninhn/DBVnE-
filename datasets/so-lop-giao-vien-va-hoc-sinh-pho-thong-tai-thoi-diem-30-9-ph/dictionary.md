# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Phân loại` | category | - | - | - | Phân loại đối tượng thống kê: Lớp, Giáo viên hoặc Học sinh. |
| `Cấp học` | category | - | - | - | Cấp học phổ thông được thống kê: Tổng số, Tiểu học, Trung học cơ sở hoặc Trung học phổ thông. |
| `Năm học` | string | - | - | năm | Năm học mà dữ liệu được thống kê. |
| `Loại hình` | category | - | - | - | Loại hình trường học: Công lập hoặc Ngoài công lập. |
| `Ghi chú` | string | - | - | - | Thông tin ghi chú bổ sung cho dữ liệu, ví dụ 'Sơ bộ' cho dữ liệu chưa chính thức. |
| `Số lớp, giáo viên và học sinh` | number | , | . | nghìn đơn vị | Số lượng lớp học, giáo viên hoặc học sinh phổ thông, tính theo nghìn đơn vị, tùy thuộc vào giá trị của cột 'Phân loại'. |
| `Chỉ số phát triển (Năm trước = 100) (%)` | number | , | . | % | Chỉ số phát triển của số liệu so với năm học trước, với năm học trước được lấy làm 100%. |
