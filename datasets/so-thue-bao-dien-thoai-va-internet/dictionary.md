# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Viễn thông` | category | - | - | - | Loại hình thuê bao viễn thông được thống kê, bao gồm số thuê bao điện thoại, số thuê bao di động (trong tổng số điện thoại) và số thuê bao internet băng rộng cố định (ADSL). |
| `Ghi chú` | string | - | - | - | Ghi chú về tính chất của dữ liệu, ví dụ: 'Sơ bộ' cho dữ liệu chưa chính thức. |
| `Tổng số - Nghìn thuê bao` | number | , | . | nghìn thuê bao | Tổng số lượng thuê bao của loại hình viễn thông tương ứng, tính bằng nghìn thuê bao. |
| `Chỉ số phát triển (Năm trước =100) (%)` | number | , | . | % | Chỉ số phát triển của số thuê bao so với năm trước đó (lấy năm trước làm 100%). |
