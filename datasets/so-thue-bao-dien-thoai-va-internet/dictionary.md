# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `chỉ số phát triển, Năm` | category | - | - | - | Loại hình thuê bao được thống kê, bao gồm tổng số thuê bao điện thoại, số thuê bao di động trong tổng số thuê bao điện thoại, và số thuê bao internet băng rộng cố định (ADSL). |
| `Ghi chú` | string | - | - | - | Ghi chú về dữ liệu, ví dụ 'Sơ bộ' cho dữ liệu chưa chính thức. Cột này chủ yếu trống. |
| `Tổng số - Nghìn thuê bao` | number | , | . | nghìn thuê bao | Tổng số lượng thuê bao của từng loại hình trong năm tương ứng, tính bằng nghìn thuê bao. |
| `Chỉ số phát triển (Năm trước =100) (%)` | number | , | . | % | Chỉ số phát triển của số lượng thuê bao so với năm trước đó (lấy năm trước làm 100%). |
