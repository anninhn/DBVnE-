# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Tỉnh/Thành phố` | category | - | - | - | Tên tỉnh, thành phố trực thuộc trung ương, vùng kinh tế - xã hội hoặc cấp quốc gia (CẢ NƯỚC). |
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Ghi chú` | string | - | - | - | Ghi chú về tình trạng dữ liệu, ví dụ 'Sơ bộ' cho dữ liệu chưa chính thức. Các giá trị trống có thể là dữ liệu đã chính thức. |
| `Tuổi thọ trung bình tính từ lúc sinh` | number | - | - | năm | Tuổi thọ trung bình của một người tính từ thời điểm sinh ra. |
