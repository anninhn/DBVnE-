# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Cấp học` | category | - | - | - | Cấp học của trường phổ thông (ví dụ: Tiểu học, Trung học cơ sở, Trung học phổ thông, hoặc Tổng số các cấp). |
| `Năm học` | string | - | - | năm học | Năm học mà dữ liệu được thống kê, thể hiện dưới dạng khoảng thời gian (ví dụ: 1995 - 1996). |
| `Ghi chú` | string | - | - | - | Thông tin ghi chú bổ sung cho dữ liệu, ví dụ 'Sơ bộ' cho biết dữ liệu chưa phải là cuối cùng. |
| `Số trường` | number | , | . | trường | Tổng số lượng trường phổ thông tại thời điểm thống kê cho từng cấp học và năm học cụ thể. |
| `Chỉ số phát triển (Năm trước = 100) (%)` | number | - | - | % | Chỉ số thể hiện mức độ phát triển của số lượng trường so với năm học trước, với năm học trước được lấy làm 100%. |
