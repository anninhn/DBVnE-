# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `chỉ số phát triển, Cấp học` | category | - | - | - | Phân loại theo cấp học phổ thông (Tiểu học, THCS, THPT, hoặc các tổ hợp) hoặc tổng số các cấp học. |
| `Năm học` | string | - | - | năm học | Khoảng thời gian của năm học được thống kê. |
| `Ghi chú` | string | - | - | - | Thông tin bổ sung về dữ liệu, ví dụ 'Sơ bộ' cho biết dữ liệu chưa chính thức. Cột này có nhiều giá trị trống. |
| `Số trường` | number | , | . | trường | Tổng số trường phổ thông tại thời điểm 30/9 của năm học tương ứng. |
| `Chỉ số phát triển (Năm trước = 100) (%)` | number | , | . | % | Chỉ số phát triển của số lượng trường phổ thông so với năm học trước, lấy năm học trước làm 100%. |
