# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Khu vực kinh tế` | category | - | - | - | Phân loại các khu vực kinh tế chính đóng góp vào Tổng sản phẩm trong nước (GDP). |
| `Ghi chú` | string | - | - | - | Ghi chú về trạng thái dữ liệu, ví dụ 'Sơ bộ' cho dữ liệu chưa chính thức. Cột này có nhiều giá trị rỗng. |
| `Giá trị (Tỷ đồng)` | number | , | . | tỷ VND | Giá trị Tổng sản phẩm trong nước (GDP) của từng khu vực kinh tế theo giá hiện hành, tính bằng tỷ đồng. |
| `Cơ cấu (%)` | number | , | . | % | Tỷ trọng đóng góp của từng khu vực kinh tế vào Tổng sản phẩm trong nước (GDP) theo giá hiện hành. |
