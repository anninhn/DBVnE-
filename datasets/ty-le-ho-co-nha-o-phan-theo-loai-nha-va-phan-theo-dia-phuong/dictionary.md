# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Địa phương` | category | - | - | - | Tên địa phương hoặc vùng kinh tế xã hội, bao gồm tổng số cả nước. |
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Ghi chú` | string | - | - | - | Ghi chú về tình trạng dữ liệu, ví dụ: 'Sơ bộ'. |
| `Chung` | number | - | - | % | Tổng tỷ lệ hộ có nhà ở, luôn là 100% (dùng để kiểm tra tổng các loại nhà). |
| `Nhà kiên cố` | number | - | - | % | Tỷ lệ hộ gia đình có nhà ở kiên cố. |
| `Nhà bán kiên cố` | number | - | - | % | Tỷ lệ hộ gia đình có nhà ở bán kiên cố. |
| `Nhà thiếu kiên cố` | number | - | - | % | Tỷ lệ hộ gia đình có nhà ở thiếu kiên cố. |
| `Nhà đơn sơ` | number | - | - | % | Tỷ lệ hộ gia đình có nhà ở đơn sơ. |
