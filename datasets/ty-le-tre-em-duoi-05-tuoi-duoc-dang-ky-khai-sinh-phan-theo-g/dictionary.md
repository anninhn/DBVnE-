# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Giới tính, vùng` | category | - | - | - | Phân loại dữ liệu theo giới tính (Nam, Nữ) hoặc theo các vùng địa lý của Việt Nam (ví dụ: Đồng bằng sông Hồng, Tây Nguyên). |
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Ghi chú` | string | - | - | - | Ghi chú về tính chất của dữ liệu, ví dụ: 'Sơ bộ' cho biết dữ liệu chưa chính thức. |
| `Tỷ lệ trẻ em dưới 05 tuổi được đăng ký khai sinh` | number | - | - | % | Tỷ lệ phần trăm trẻ em dưới 5 tuổi đã được đăng ký khai sinh trong tổng số trẻ em dưới 5 tuổi. |
