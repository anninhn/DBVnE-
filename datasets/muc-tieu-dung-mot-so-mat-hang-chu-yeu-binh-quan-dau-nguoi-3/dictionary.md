# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Phân tổ` | category | - | - | - | Tên mặt hàng hoặc nhóm mặt hàng tiêu dùng, kèm theo đơn vị tính của mặt hàng đó (ví dụ: Gạo (Kg), Thịt các loại (Kg), Rượu, bia (Lít)). |
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Ghi chú` | string | - | - | - | Ghi chú bổ sung cho dữ liệu, ví dụ: 'Sơ bộ' cho các số liệu chưa chính thức. |
| `Chung` | number | - | - | unknown | Mức tiêu dùng bình quân đầu người của mặt hàng tương ứng trên toàn quốc. Đơn vị tính được chỉ rõ trong cột 'Phân tổ'. |
| `Thành thị` | number | - | - | unknown | Mức tiêu dùng bình quân đầu người của mặt hàng tương ứng tại khu vực thành thị. Đơn vị tính được chỉ rõ trong cột 'Phân tổ'. |
| `Nông thôn` | number | - | - | unknown | Mức tiêu dùng bình quân đầu người của mặt hàng tương ứng tại khu vực nông thôn. Đơn vị tính được chỉ rõ trong cột 'Phân tổ'. |
