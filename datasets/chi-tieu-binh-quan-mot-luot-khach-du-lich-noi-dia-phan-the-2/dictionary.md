# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Mục đích` | category | - | - | - | Các khoản mục chi tiêu của khách du lịch nội địa (ví dụ: Thuê phòng, Ăn uống, Đi lại, Mua hàng hóa, v.v.). |
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu chi tiêu. |
| `Ghi chú` | category | - | - | - | Ghi chú về tính chất của dữ liệu, ví dụ 'Sơ bộ' cho dữ liệu chưa chính thức. |
| `Trị giá (Nghìn đồng)` | number | , | . | nghìn đồng | Giá trị chi tiêu bình quân cho một lượt khách du lịch nội địa theo từng mục đích, tính bằng nghìn đồng. |
| `Cơ cấu (%)` | number | , | . | % | Tỷ lệ phần trăm của từng khoản chi tiêu so với tổng chi tiêu bình quân của một lượt khách du lịch nội địa. |
