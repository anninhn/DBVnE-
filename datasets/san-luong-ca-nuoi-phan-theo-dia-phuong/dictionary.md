# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Tỉnh, thành phố` | category | - | - | - | Tên tỉnh, thành phố hoặc vùng kinh tế. Bao gồm cả dữ liệu tổng hợp cho 'CẢ NƯỚC' và các vùng. |
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Ghi chú` | string | - | - | - | Ghi chú về tình trạng dữ liệu, ví dụ 'Sơ bộ' cho dữ liệu chưa chính thức. Cột này có nhiều giá trị rỗng. |
| `Sản lượng cá nuôi` | number | , | . | tấn | Tổng sản lượng cá nuôi được thu hoạch trong năm. |
