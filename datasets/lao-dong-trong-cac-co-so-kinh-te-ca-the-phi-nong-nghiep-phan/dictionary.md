# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Tỉnh/thành phố` | category | - | - | - | Tên tỉnh/thành phố hoặc vùng kinh tế, bao gồm cả số liệu toàn quốc. |
| `Năm` | number | - | - | năm | Năm thống kê số liệu. |
