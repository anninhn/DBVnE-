# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Cấp quản lý` | category | - | - | - | Cấp quản lý của vốn đầu tư, bao gồm Tổng số, Trung ương và Địa phương. |
| `Ghi chú` | string | - | - | - | Ghi chú về dữ liệu, ví dụ 'Sơ bộ' cho các số liệu chưa chính thức. |
| `Giá hiện hành (Tỷ đồng)` | number | , | . | tỷ VND | Vốn đầu tư thực hiện tính theo giá hiện hành. |
| `Cơ cấu (%)` | number | , | . | % | Tỷ trọng của vốn đầu tư thực hiện so với tổng số. |
| `Giá so sánh 2010 (Tỷ đồng )` | number | , | . | tỷ VND | Vốn đầu tư thực hiện tính theo giá so sánh năm 2010. |
| `Chỉ số phát triển (Năm trước = 100) (%)` | number | , | . | % | Chỉ số phát triển vốn đầu tư thực hiện so với năm trước (lấy năm trước làm gốc 100%). |
