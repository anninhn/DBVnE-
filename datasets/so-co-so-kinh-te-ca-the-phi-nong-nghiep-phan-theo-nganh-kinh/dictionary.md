# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Ngành kinh tế` | category | - | - | - | Ngành kinh tế mà cơ sở kinh tế cá thể phi nông nghiệp hoạt động, bao gồm tổng số và các ngành chi tiết như công nghiệp, thương mại, dịch vụ. |
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Ghi chú` | string | - | - | - | Thông tin bổ sung về dữ liệu, ví dụ 'Sơ bộ' cho biết dữ liệu chưa phải là cuối cùng. |
| `Số cơ sở kinh tế cá thể phi nông nghiệp` | number | - | - | unknown | Tổng số lượng cơ sở kinh tế cá thể phi nông nghiệp được thống kê. |
