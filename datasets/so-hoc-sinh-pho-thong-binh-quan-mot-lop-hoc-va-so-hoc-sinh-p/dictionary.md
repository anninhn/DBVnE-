# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Số học sinh phổ thông` | category | - | - | - | Chỉ số thống kê, thể hiện dữ liệu là bình quân số học sinh trên một lớp học hoặc bình quân số học sinh trên một giáo viên. |
| `Cấp học` | category | - | - | - | Cấp học của học sinh phổ thông, bao gồm Tổng số, Tiểu học, Trung học cơ sở và Trung học phổ thông. |
| `Năm học` | string | - | - | năm học | Năm học mà số liệu được thống kê. |
| `Ghi chú` | string | - | - | - | Các ghi chú bổ sung về dữ liệu, ví dụ 'Sơ bộ' cho dữ liệu chưa chính thức. |
| `Công lập` | number | - | - | học sinh/đơn vị | Số học sinh bình quân trên một lớp học hoặc một giáo viên tại các trường công lập. Đơn vị cụ thể phụ thuộc vào giá trị của cột 'Số học sinh phổ thông'. |
| `Ngoài công lập` | number | - | - | học sinh/đơn vị | Số học sinh bình quân trên một lớp học hoặc một giáo viên tại các trường ngoài công lập. Đơn vị cụ thể phụ thuộc vào giá trị của cột 'Số học sinh phổ thông'. |
