# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Loại thiệt hại` | category | - | - | - | Phân loại các loại thiệt hại do thiên tai gây ra, bao gồm thiệt hại về người (chết, mất tích, bị thương), nhà ở (sập đổ, ngập nước, tốc mái), nông nghiệp (diện tích lúa, hoa màu bị thiệt hại) và tổng giá trị thiệt hại. |
| `Năm` | number | - | - | năm | Năm xảy ra thiệt hại do thiên tai. |
| `Ghi chú` | category | - | - | - | Ghi chú bổ sung về dữ liệu, ví dụ: dữ liệu sơ bộ hoặc có đánh dấu đặc biệt. |
| `Thiệt hại do thiên tai` | number | , | . | variable | Giá trị thiệt hại định lượng tương ứng với từng loại thiệt hại và năm cụ thể. Đơn vị của giá trị này thay đổi tùy thuộc vào 'Loại thiệt hại' (ví dụ: số người, số nhà, diện tích ha, giá trị tỷ đồng). |
