# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Địa phương` | category | - | - | - | Tên địa phương, bao gồm cấp quốc gia (CẢ NƯỚC), các vùng kinh tế - xã hội và các tỉnh/thành phố trực thuộc trung ương. |
| `Năm` | number | - | - | năm | Năm thống kê số liệu. |
| `Tổng số` | number | - | - | giường | Tổng số giường bệnh trên toàn địa phương trong năm thống kê. |
| `Công lập` | number | - | - | giường | Số giường bệnh thuộc khối công lập trên địa bàn trong năm thống kê. |
| `Ngoài công lập` | number | - | - | giường | Số giường bệnh thuộc khối ngoài công lập (tư nhân, liên doanh,...) trên địa bàn trong năm thống kê. |
