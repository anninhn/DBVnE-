# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Ngành hoạt động` | category | - | - | - | Phân loại ngành hoạt động khai thác thủy sản, bao gồm Tổng số, Khai thác biển, Cá (Khai thác biển) và Khai thác nội địa. |
| `Ghi chú` | string | - | - | - | Ghi chú bổ sung cho dữ liệu, ví dụ 'Sơ bộ' cho các số liệu chưa chính thức. Hầu hết các dòng không có ghi chú. |
| `Sản lượng (Nghìn tấn)` | number | , | . | nghìn tấn | Tổng sản lượng thủy sản khai thác được trong năm. |
| `Chỉ số phát triển (Năm trước = 100) (%)` | number | , | . | % | Chỉ số phát triển sản lượng thủy sản khai thác so với năm trước đó (lấy năm trước làm 100%). |
