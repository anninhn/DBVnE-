# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Một số cây lâu năm` | category | - | - | - | Tên các loại cây lâu năm được thống kê, bao gồm các nhóm cây ăn quả và cây công nghiệp. |
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Ghi chú` | string | - | - | - | Các ghi chú đặc biệt về dữ liệu, ví dụ 'Sơ bộ' cho một số năm hoặc loại cây. Hầu hết các dòng không có ghi chú. |
| `Diện tích (Nghìn ha)` | number | , | . | nghìn ha | Tổng diện tích trồng các loại cây lâu năm, tính bằng nghìn hecta. |
| `Chỉ số phát triển (Năm trước =100) (%)` | number | , | . | % | Chỉ số phát triển diện tích của cây lâu năm so với năm trước đó (lấy năm trước làm gốc 100%). |
