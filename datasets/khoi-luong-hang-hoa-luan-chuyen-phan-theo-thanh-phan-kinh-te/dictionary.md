# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Thành phần kinh tế` | category | - | - | - | Thành phần kinh tế sở hữu hoặc quản lý hoạt động vận tải hàng hóa. |
| `Ghi chú` | string | - | - | - | Ghi chú bổ sung cho dữ liệu, ví dụ 'Sơ bộ' cho dữ liệu chưa chính thức. Cột này chủ yếu trống. |
| `Khối lượng (Triệu tấn.km)` | number | , | . | triệu tấn.km | Tổng khối lượng hàng hóa được vận chuyển nhân với quãng đường vận chuyển, tính bằng triệu tấn.km. |
| `Chỉ số phát triển (Năm trước = 100) (%)` | number | , | . | % | Chỉ số phát triển của khối lượng hàng hóa luân chuyển so với năm trước đó, lấy năm trước làm gốc 100%. |
