# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Chỉ số phát triển` | category | - | - | - | Chỉ số thống kê về cơ sở vật chất và nhân lực trong giáo dục mầm non, bao gồm trường học, lớp học, giáo viên, học sinh và các chỉ số bình quân. |
| `Năm học` | string | - | - | năm học | Năm học áp dụng cho các số liệu thống kê. |
| `Phân tổ, Loại hình` | category | - | - | - | Phân loại cơ sở giáo dục theo loại hình công lập hoặc ngoài công lập. |
| `Tổng số` | number | , | . | unknown | Tổng số lượng của chỉ số phát triển tương ứng (ví dụ: tổng số trường học, tổng số lớp học, tổng số giáo viên, tổng số học sinh). |
| `Chỉ số phát triển (Năm trước = 100) (%)` | number | , | . | % | Tỷ lệ phát triển của chỉ số so với năm học trước, lấy năm trước làm 100%. |
