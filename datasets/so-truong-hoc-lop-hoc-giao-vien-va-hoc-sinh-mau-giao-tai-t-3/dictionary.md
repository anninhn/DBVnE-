# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Chỉ số phát triển, Phân tổ` | category | - | - | - | Các chỉ số thống kê về giáo dục mẫu giáo, bao gồm số lượng trường học, lớp học, giáo viên, học sinh và các chỉ số bình quân liên quan. |
| `Năm học` | string | - | - | năm học | Năm học áp dụng cho các số liệu thống kê. |
| `Loại hình` | category | - | - | - | Loại hình cơ sở giáo dục mẫu giáo: công lập hoặc ngoài công lập. |
| `Tổng số` | number | , | . | unknown | Tổng số lượng của chỉ số phát triển tương ứng trong năm học và loại hình cụ thể. |
| `Chỉ số phát triển (Năm trước = 100) (%)` | number | , | . | % | Chỉ số biến động (tăng/giảm) của số liệu so với năm học liền trước, với năm trước được lấy làm 100%. |
