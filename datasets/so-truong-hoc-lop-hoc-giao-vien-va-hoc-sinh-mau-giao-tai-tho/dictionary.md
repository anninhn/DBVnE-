# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Chỉ số phát triển, Phân tổ` | category | - | - | - | Loại chỉ số thống kê hoặc đối tượng được phân tích (ví dụ: Trường học, Lớp học, Giáo viên, Học sinh mẫu giáo). |
| `Năm học` | string | - | - | năm học | Khoảng thời gian của năm học, ví dụ: 1995-1996. |
| `Tổng số` | number | , | . | unknown | Tổng số lượng của chỉ số được thống kê (ví dụ: tổng số trường học, tổng số giáo viên, tổng số học sinh). |
| `Chỉ số phát triển (Năm trước = 100) (%)` | number | , | . | % | Chỉ số phát triển của năm học hiện tại so với năm học trước đó, lấy năm trước làm 100%. |
