# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `chỉ số phát triển, Cấp học` | category | - | - | - | Cấp học của các trường phổ thông, bao gồm tổng số và các cấp học cụ thể như tiểu học, trung học cơ sở, trung học phổ thông. |
| `Năm học` | string | - | - | năm học | Năm học mà dữ liệu được thống kê, ví dụ 2020-2021. |
| `Loại hình` | category | - | - | - | Phân loại trường học theo hình thức sở hữu: công lập hoặc ngoài công lập. |
| `Ghi chú` | string | - | - | - | Các ghi chú bổ sung về dữ liệu, ví dụ 'Sơ bộ' cho biết dữ liệu chưa phải cuối cùng. |
| `Số trường` | number | , | . | trường | Tổng số lượng trường phổ thông được thống kê. |
| `Chỉ số phát triển (Năm trước = 100) (%)` | number | , | . | % | Chỉ số tăng trưởng hoặc giảm sút của số trường so với năm học trước, lấy năm trước làm 100%. |
