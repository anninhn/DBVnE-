# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Cấp học` | category | - | - | - | Cấp học của các trường phổ thông, bao gồm tổng số và các cấp học cụ thể như Tiểu học, Trung học cơ sở, Trung học phổ thông, và các cấp kết hợp. |
| `Năm học` | category | - | - | năm học | Năm học mà dữ liệu về số trường được thống kê, ví dụ: 2020-2021. |
| `Loại hình` | category | - | - | - | Loại hình trường học, bao gồm công lập và ngoài công lập. |
| `Ghi chú` | string | - | - | - | Thông tin bổ sung hoặc tình trạng của dữ liệu, ví dụ 'Sơ bộ' cho biết dữ liệu chưa phải là chính thức. |
| `Số trường` | number | , | . | trường | Tổng số trường phổ thông được thống kê. |
| `Chỉ số phát triển (Năm trước = 100) (%)` | number | , | . | % | Chỉ số phát triển số trường so với năm học trước, lấy năm trước làm 100%. |
