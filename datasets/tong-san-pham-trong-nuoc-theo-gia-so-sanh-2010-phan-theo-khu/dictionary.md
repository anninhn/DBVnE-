# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Khu vực kinh tế` | category | - | - | - | Phân loại các khu vực kinh tế đóng góp vào GDP, bao gồm Tổng số, Nông, lâm nghiệp và thuỷ sản, Công nghiệp và xây dựng, Dịch vụ, và Thuế sản phẩm trừ trợ cấp sản phẩm. |
| `Ghi chú` | string | - | - | - | Ghi chú về tình trạng dữ liệu, ví dụ 'Sơ bộ' cho các số liệu tạm thời hoặc chưa chính thức. |
| `Giá trị (Tỷ đồng)` | number | , | . | tỷ VND | Giá trị Tổng sản phẩm trong nước (GDP) của từng khu vực kinh tế, tính theo giá so sánh năm 2010. |
| `Chỉ số phát triển (Năm trước = 100) (%)` | number | , | . | % | Chỉ số tăng trưởng của Tổng sản phẩm trong nước theo khu vực kinh tế so với năm trước đó (năm trước được lấy làm 100%). |
