# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Địa phương` | category | - | - | - | Tên địa phương hoặc vùng kinh tế, bao gồm cả tổng số toàn quốc, các vùng và các tỉnh/thành phố. |
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Ghi chú` | string | - | - | - | Ghi chú về tình trạng dữ liệu (ví dụ: 'Sơ bộ'). Cột này có thể trống. |
| `Tỷ lệ hộ nghèo` | number | , | . | % | Tỷ lệ hộ nghèo theo chuẩn nghèo đa chiều của địa phương trong năm tương ứng. |
