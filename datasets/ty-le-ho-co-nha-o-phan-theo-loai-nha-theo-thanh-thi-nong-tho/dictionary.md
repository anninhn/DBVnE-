# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Phân tổ` | category | - | - | - | Các nhóm phân loại dữ liệu, bao gồm cả nước, thành thị, nông thôn, các vùng kinh tế-xã hội và nhóm thu nhập. |
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Ghi chú` | string | - | - | - | Ghi chú về tình trạng dữ liệu, ví dụ 'Sơ bộ' cho các số liệu chưa chính thức. |
| `Chung` | number | - | - | % | Tổng tỷ lệ hộ có nhà ở, luôn là 100% để thể hiện tổng các loại nhà. |
| `Nhà kiên cố` | number | - | - | % | Tỷ lệ hộ có nhà ở kiên cố. |
| `Nhà bán kiên cố` | number | - | - | % | Tỷ lệ hộ có nhà ở bán kiên cố. |
| `Nhà thiếu kiên cố` | number | - | - | % | Tỷ lệ hộ có nhà ở thiếu kiên cố. |
| `Nhà đơn sơ` | number | - | - | % | Tỷ lệ hộ có nhà ở đơn sơ. |
