# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Giới tính` | category | - | - | - | Giới tính của lao động có việc làm, bao gồm Tổng số, Nam và Nữ. |
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Ghi chú` | category | - | - | - | Ghi chú về tính chất của dữ liệu (ví dụ: Sơ bộ). Cột này có thể trống. |
| `Số lao động có việc làm trong nền kinh tế` | number | - | - | nghìn người | Tổng số lao động có việc làm trong nền kinh tế quốc dân. |
