# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Tỉnh, thành phố` | category | - | - | - | Tên tỉnh, thành phố trực thuộc trung ương, vùng kinh tế hoặc tổng hợp cả nước. |
| `Năm` | number | - | - | năm | Năm thống kê số liệu. |
| `Ghi chú` | string | - | - | - | Ghi chú về tính chất của số liệu (ví dụ: 'Sơ bộ' cho số liệu chưa chính thức). |
| `Năng suất lao động` | number | , | . | triệu VND/người | Năng suất lao động của một địa phương hoặc cả nước trong năm, tính theo giá hiện hành. |
