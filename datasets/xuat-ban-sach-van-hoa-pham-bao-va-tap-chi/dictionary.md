# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Cách tính` | category | - | - | - | Phương pháp tính toán dữ liệu, bao gồm 'Tổng số' hoặc 'Chỉ số phát triển (Năm trước = 100) %'. |
| `Loại ấn xuất bản phẩm` | category | - | - | - | Loại ấn phẩm được xuất bản, ví dụ: 'SÁCH- Đầu sách', 'SÁCH- Triệu bản', 'Phân theo cấp quản lý', 'Phân theo loại sách'. |
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Ghi chú` | category | - | - | - | Ghi chú về dữ liệu, ví dụ 'Sơ bộ' cho dữ liệu chưa chính thức. Cột này có nhiều giá trị rỗng. |
| `Xuất bản sách, văn hóa phẩm, báo và tạp chí` | number | , | . | unknown | Số lượng xuất bản của sách, văn hóa phẩm, báo và tạp chí. Đơn vị cụ thể phụ thuộc vào giá trị của cột 'Loại ấn xuất bản phẩm' (ví dụ: đầu sách, triệu bản). |
