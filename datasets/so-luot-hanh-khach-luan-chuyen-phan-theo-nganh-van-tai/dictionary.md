# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Ngành` | category | - | - | - | Ngành vận tải bao gồm: Tổng số, Đường sắt, Đường bộ, Đường sông, Đường hàng không. |
| `Ghi chú` | string | - | - | - | Ghi chú về dữ liệu, ví dụ 'Sơ bộ' cho các số liệu chưa chính thức. Cột này chủ yếu trống. |
| `Lượt hành khách (Triệu lượt người.km)` | number | , | . | triệu lượt người.km | Tổng số lượt hành khách luân chuyển theo từng ngành vận tải, tính bằng triệu lượt người.km. |
| `Chỉ số phát triển (Nãm trước =100) (%)` | number | , | . | % | Chỉ số phát triển lượt hành khách luân chuyển so với năm trước đó (năm trước = 100%). |
