# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Gia súc, gia cầm` | category | - | - | - | Loại gia súc hoặc gia cầm được thống kê. |
| `Ghi chú` | string | - | - | - | Thông tin ghi chú bổ sung cho dữ liệu, ví dụ: 'Sơ bộ'. |
| `Số lượng (Nghìn con)` | number | , | . | nghìn con | Tổng số lượng gia súc, gia cầm được thống kê, tính bằng nghìn con. |
| `Chỉ số phát triển (Năm trước =100) (%)` | number | , | . | % | Chỉ số phát triển của số lượng gia súc, gia cầm so với năm trước đó (năm trước = 100%). |
