# Dictionary

| Column | Type | Unit | Description |
|--------|------|------|-------------|
| `Tên lĩnh vực` | string | - | Tên của lĩnh vực quản lý nhà nước, ví dụ: thành lập và hoạt động ngân hàng, hoạt động ngoại hối. |
| `Số lượng thủ tục` | number | thủ tục | Tổng số thủ tục hành chính thuộc lĩnh vực quản lý tương ứng. |
| `Cơ quan quản lý sau sáp nhập` | string | - | Tên cơ quan nhà nước chịu trách nhiệm quản lý lĩnh vực sau khi có các thay đổi về tổ chức hoặc sáp nhập. |
| `Cơ quan quản lý lĩnh vực trước sáp nhập` | string | - | Tên cơ quan nhà nước chịu trách nhiệm quản lý lĩnh vực trước khi có các thay đổi về tổ chức hoặc sáp nhập. |
| `Nguồn Văn bản Quy phạm pháp luật quy định quản lý nhà nước theo lĩnh vực` | string | - | Thông tin về văn bản quy phạm pháp luật (Nghị định, Thông tư, Pháp lệnh) quy định việc quản lý nhà nước đối với lĩnh vực. |
