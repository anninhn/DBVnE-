# Dictionary

| Column | Type | Unit | Description |
|--------|------|------|-------------|
| `Tên lĩnh vực` | string | - | Tên của lĩnh vực quản lý nhà nước, bao gồm các thủ tục hành chính liên quan. |
| `Số lượng thủ tục` | number | thủ tục | Tổng số thủ tục hành chính thuộc lĩnh vực quản lý tương ứng. |
| `Cơ quan quản lý sau sáp nhập` | string | - | Tên cơ quan nhà nước chịu trách nhiệm quản lý lĩnh vực sau khi có sự thay đổi hoặc sáp nhập cơ cấu tổ chức. |
| `Cơ quan quản lý lĩnh vực trước sáp nhập` | string | - | Tên cơ quan nhà nước chịu trách nhiệm quản lý lĩnh vực trước khi có sự thay đổi hoặc sáp nhập cơ cấu tổ chức. |
| `Nguồn Văn bản Quy phạm pháp luật quy định quản lý nhà nước theo lĩnh vực` | string | - | Thông tin về văn bản quy phạm pháp luật (Nghị định, Thông tư, Pháp lệnh, v.v.) quy định việc quản lý nhà nước đối với lĩnh vực cụ thể. |
