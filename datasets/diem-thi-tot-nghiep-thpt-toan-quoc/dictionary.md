# Dictionary

| Column | Type | Unit | Description |
|--------|------|------|-------------|
| `number` | string | - | Số thứ tự thí sinh trong danh sách (có thể là cục bộ hoặc một phần của mã định danh). |
| `code` | string | - | Mã tỉnh thành dự thi. Giá trị '01' tương ứng với Hà Nội. |
| `year` | number | năm | Năm diễn ra kỳ thi tốt nghiệp THPT. |
| `Toán` | number | điểm | Điểm thi môn Toán của thí sinh. |
| `Ngữ văn` | number | điểm | Điểm thi môn Ngữ văn của thí sinh. |
| `Ngoại ngữ` | number | điểm | Điểm thi môn Ngoại ngữ của thí sinh. |
| `Vật lý` | number | điểm | Điểm thi môn Vật lý của thí sinh. |
| `Hóa học` | number | điểm | Điểm thi môn Hóa học của thí sinh. |
| `Lịch sử` | number | điểm | Điểm thi môn Lịch sử của thí sinh. |
| `Địa lý` | number | điểm | Điểm thi môn Địa lý của thí sinh. |
| `Sinh học` | number | điểm | Điểm thi môn Sinh học của thí sinh. |
| `Giáo dục công dân` | number | điểm | Điểm thi môn Giáo dục công dân của thí sinh. |
| `Tin học` | number | điểm | Điểm thi môn Tin học của thí sinh (nếu có). |
| `Công nghệ Công nghiệp` | number | điểm | Điểm thi môn Công nghệ Công nghiệp của thí sinh (nếu có). |
| `Công nghệ Nông nghiệp` | number | điểm | Điểm thi môn Công nghệ Nông nghiệp của thí sinh (nếu có). |
| `Giáo dục kinh tế và pháp luật` | number | điểm | Điểm thi môn Giáo dục kinh tế và pháp luật của thí sinh (nếu có). |
| `mã môn ngoại ngữ` | category | - | Mã môn ngoại ngữ mà thí sinh đã chọn dự thi (ví dụ: Anh, Pháp, Đức, Nhật, Trung, Nga). |
| `SOBAODANH` | string | - | Số báo danh duy nhất của thí sinh. |
| `Tỉnh thành` | category | - | Tên tỉnh thành nơi thí sinh dự thi. |
