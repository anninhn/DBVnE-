# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Thành phần kinh tế` | category | - | - | - | Phân loại các thành phần kinh tế bao gồm Tổng số, Kinh tế Nhà nước, Kinh tế ngoài Nhà nước và Khu vực có vốn đầu tư nước ngoài. |
| `Ghi chú` | string | - | - | - | Ghi chú về tình trạng dữ liệu (ví dụ: 'Sơ bộ' cho dữ liệu chưa chính thức). |
| `Tổng số (Nghìn người)` | number | , | . | nghìn người | Tổng số lao động có việc làm trong nền kinh tế, tính theo nghìn người. |
| `Cơ cấu (%)` | number | , | . | % | Tỷ lệ phần trăm cơ cấu lao động có việc làm theo từng thành phần kinh tế so với tổng số. |
