# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `scope` | category | - | - | - | Phạm vi địa lý của dữ liệu, có thể là cấp tỉnh/thành phố (province) hoặc cấp vùng (region). |
| `province` | category | - | - | - | Tên tỉnh hoặc thành phố trực thuộc trung ương. Giá trị rỗng khi dữ liệu ở cấp vùng hoặc toàn quốc. |
| `region` | category | - | - | - | Tên vùng kinh tế - xã hội hoặc 'CẢ NƯỚC'. Giá trị rỗng khi dữ liệu ở cấp tỉnh. |
| `year` | number | - | - | năm | Năm thống kê dữ liệu. |
| `metric` | category | - | - | - | Chỉ số đo lường, ở đây là sản lượng khai thác gỗ. |
| `value` | number | . | , | nghìn m³ | Giá trị sản lượng gỗ khai thác. |
| `unit` | string | - | - | - | Đơn vị của giá trị sản lượng gỗ khai thác. |
| `flag` | string | - | - | - | Cờ hoặc ghi chú đặc biệt liên quan đến dữ liệu, ví dụ: thay đổi phương pháp tính toán hoặc dữ liệu sơ bộ. |
