# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Loại trường` | category | - | - | - | Phân loại trường đại học và cao đẳng (Tổng số, Công lập, Ngoài công lập). |
| `Trình độ` | category | - | - | - | Trình độ học vấn của giảng viên (Tổng số, Trên đại học, Đại học, cao đẳng, Trình độ khác). |
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Số giảng viên` | number | , | . | người | Tổng số lượng giảng viên theo từng loại trường, trình độ và năm. |
| `Chỉ số phát triển (Năm trước = 100) - (%)` | number | , | . | % | Chỉ số phát triển số lượng giảng viên so với năm trước đó (năm trước được lấy làm 100%). |
