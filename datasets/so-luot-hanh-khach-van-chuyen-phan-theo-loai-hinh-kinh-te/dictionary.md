# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Thành phần kinh tế` | category | - | - | - | Phân loại các thành phần kinh tế tham gia vận chuyển hành khách, bao gồm Tổng số, Kinh tế Nhà nước, Kinh tế ngoài Nhà nước và Khu vực có vốn đầu tư nước ngoài. |
| `Ghi chú` | string | - | - | - | Ghi chú về tình trạng dữ liệu, ví dụ 'Sơ bộ' cho dữ liệu chưa chính thức. |
| `Lượt hành khách (Triệu lượt người)` | number | , | . | triệu lượt người | Tổng số lượt hành khách được vận chuyển trong năm, tính bằng triệu lượt người. |
| `Chỉ số phát triển (Năm trước = 100) (%)` | number | , | . | % | Chỉ số phát triển số lượt hành khách vận chuyển so với năm trước đó (lấy năm trước làm 100%). |
