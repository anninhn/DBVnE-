# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Khu vực` | category | - | - | - | Loại hình kinh tế vận chuyển hàng hóa, bao gồm Tổng số, Kinh tế Nhà nước, Kinh tế ngoài Nhà nước và Khu vực có vốn đầu tư nước ngoài. |
| `Ghi chú` | string | - | - | - | Ghi chú về tính chất của dữ liệu, thường chỉ xuất hiện cho một số ít dòng (ví dụ: 'Sơ bộ'). |
| `Khối lượng (Nghìn tấn)` | number | - | - | nghìn tấn | Tổng khối lượng hàng hóa được vận chuyển. |
| `Chỉ số phát triển (Năm trước = 100) (%)` | number | - | - | % | Chỉ số phát triển khối lượng hàng hóa vận chuyển so với năm trước đó (lấy năm trước làm 100%). |
