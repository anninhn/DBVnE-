# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Loại chi` | category | - | - | - | Phân loại các khoản chi ngân sách nhà nước (ví dụ: Tổng chi, Chi đầu tư phát triển, Chi giáo dục, v.v.). |
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Ghi chú` | string | - | - | - | Ghi chú bổ sung cho dữ liệu, ví dụ: 'Ước tính' cho các số liệu dự kiến. |
| `Tỷ lệ (%)` | number | , | . | % | Tỷ lệ phần trăm của loại chi ngân sách nhà nước tương ứng so với Tổng sản phẩm trong nước (GDP). |
