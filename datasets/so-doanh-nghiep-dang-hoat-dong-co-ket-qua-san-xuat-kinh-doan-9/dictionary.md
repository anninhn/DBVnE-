# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Loại hình doanh nghiệp` | category | - | - | - | Phân loại doanh nghiệp theo hình thức sở hữu hoặc loại hình pháp lý (ví dụ: Doanh nghiệp Nhà nước, Tư nhân, Doanh nghiệp có vốn đầu tư nước ngoài). |
| `Quy mô vốn` | category | - | - | tỷ đồng | Phân loại doanh nghiệp theo quy mô vốn đăng ký hoặc vốn điều lệ, với các khoảng giá trị khác nhau. |
| `Doanh nghiệp` | number | - | - | doanh nghiệp | Số lượng doanh nghiệp đang hoạt động có kết quả sản xuất kinh doanh trong từng loại hình và quy mô vốn. |
| `Cơ cấu (%)` | number | - | - | % | Tỷ lệ phần trăm của số lượng doanh nghiệp trong từng loại hình/quy mô vốn so với tổng số doanh nghiệp. |
