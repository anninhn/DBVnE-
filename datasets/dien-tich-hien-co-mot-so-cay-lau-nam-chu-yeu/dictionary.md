# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Một số cây lâu năm` | category | - | - | - | Tên các loại cây lâu năm chính được thống kê, bao gồm các nhóm cây ăn quả và cây công nghiệp. |
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Ghi chú` | string | - | - | - | Ghi chú bổ sung về dữ liệu, ví dụ: 'Sơ bộ' cho biết dữ liệu chưa phải là số liệu chính thức cuối cùng. |
| `Diện tích (Nghìn ha )` | number | , | . | nghìn ha | Tổng diện tích hiện có của từng loại cây lâu năm được thống kê. |
| `Chỉ số phát triển (Năm trước =100) (%)` | number | , | . | % | Chỉ số phát triển diện tích của từng loại cây lâu năm so với năm trước đó (năm trước được lấy làm 100%). |
