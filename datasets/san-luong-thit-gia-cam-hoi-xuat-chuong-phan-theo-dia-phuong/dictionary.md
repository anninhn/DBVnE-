# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Tỉnh, thành phố` | category | - | - | - | Tên tỉnh, thành phố hoặc vùng kinh tế. Bao gồm cả tổng 'CẢ NƯỚC'. |
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Ghi chú` | string | - | - | - | Ghi chú về dữ liệu, ví dụ 'Sơ bộ' cho các số liệu chưa chính thức. Cột này thường để trống. |
| `Sản lượng thịt gia cầm hơi xuất chuồng` | number | - | - | tấn | Tổng sản lượng thịt gia cầm (tính theo trọng lượng hơi, bao gồm cả thịt và xương) xuất chuồng trong năm. |
