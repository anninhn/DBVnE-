# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Loại hình doanh nghiệp` | category | - | - | - | Phân loại doanh nghiệp theo hình thức sở hữu hoặc nguồn vốn, bao gồm tổng số và các loại hình cụ thể như doanh nghiệp nhà nước, tư nhân, có vốn đầu tư nước ngoài. |
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu doanh thu thuần. |

| `Cơ cấu (%)` | number | , | . | % | Tỷ lệ phần trăm doanh thu thuần của từng loại hình doanh nghiệp so với tổng doanh thu thuần của tất cả các loại hình trong cùng năm. |
