# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Tỉnh/Thành phố` | category | - | - | - | Tên tỉnh/thành phố trực thuộc trung ương, vùng kinh tế - xã hội hoặc 'CẢ NƯỚC'. |
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Ghi chú` | category | - | - | - | Thông tin ghi chú về dữ liệu, ví dụ: 'Sơ bộ' cho dữ liệu chưa chính thức. |
| `Tỷ lệ tăng dân số` | number | , | . | % | Tỷ lệ tăng dân số của địa phương hoặc toàn quốc trong năm, tính theo phần trăm. |
