# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Ngành công nghiệp` | category | - | - | - | Tên ngành hoặc nhóm ngành công nghiệp, bao gồm cả tổng số và các ngành chi tiết như khai khoáng, chế biến chế tạo. |
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Ghi chú` | string | - | - | - | Thông tin bổ sung về trạng thái của dữ liệu, ví dụ 'Sơ bộ' cho dữ liệu chưa chính thức. Phần lớn các dòng không có ghi chú. |
| `Chỉ số sản xuất công nghiệp` | number | , | . | % | Chỉ số sản xuất công nghiệp (IPI) của ngành tương ứng, thể hiện tốc độ tăng trưởng hoặc suy giảm so với kỳ gốc. Giá trị 100% thường là mức của năm gốc. |
