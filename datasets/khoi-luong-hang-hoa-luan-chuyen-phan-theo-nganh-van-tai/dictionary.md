# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Ngành` | category | - | - | - | Ngành vận tải bao gồm Tổng số, Đường sắt, Đường bộ, Đường sông, Đường biển và Đường hàng không. |
| `Ghi chú` | string | - | - | - | Ghi chú bổ sung cho dữ liệu, ví dụ 'Sơ bộ' cho các số liệu chưa chính thức. Cột này có nhiều giá trị trống. |
| `Khối lượng hàng hoá luân chuyển (Triệu tấn.km)` | number | , | . | Triệu tấn.km | Tổng khối lượng hàng hóa được vận chuyển nhân với quãng đường vận chuyển, tính bằng triệu tấn.km. |
| `Chỉ số phát triển (Năm trước =100) (%)` | number | , | . | % | Chỉ số thể hiện tốc độ tăng trưởng khối lượng hàng hóa luân chuyển so với năm trước đó (năm trước = 100%). |
