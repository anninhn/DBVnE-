| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `chỉ số phát trển, Năm` | category | - | - | - | Ngành vận tải hoặc tổng số. Bao gồm các loại hình: Tổng số, Đường sắt, Đường bộ, Đường sông, Đường biển, Đường hàng không. |
