# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Ngành` | category | - | - | - | Ngành vận tải hàng hóa, bao gồm Tổng số, Đường sắt, Đường bộ, Đường sông, Đường biển và Đường hàng không. |
| `Ghi chú` | string | - | - | - | Ghi chú về tính chất của dữ liệu (ví dụ: Sơ bộ). Cột này có thể chứa giá trị rỗng. |
| `Giá trị (Nghìn tấn)` | number | , | . | nghìn tấn | Khối lượng hàng hóa vận chuyển thực tế trong năm, tính bằng nghìn tấn. |
| `Chỉ số phát triển (Năm trước =100) (%)` | number | , | . | % | Chỉ số phát triển khối lượng hàng hóa vận chuyển so với năm trước đó (năm trước = 100). |
