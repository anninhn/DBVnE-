# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Tỉnh/thành phố` | category | - | - | - | Tên tỉnh, thành phố trực thuộc trung ương hoặc vùng kinh tế, bao gồm cả tổng số 'CẢ NƯỚC'. |
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Ghi chú` | string | - | - | - | Ghi chú về tính chất của dữ liệu (ví dụ: 'Sơ bộ' hoặc để trống). |
| `Số cơ sở kinh tế cá thể phi nông nghiệp` | number | - | - | cơ sở | Tổng số cơ sở kinh tế cá thể hoạt động trong các ngành phi nông nghiệp. |
