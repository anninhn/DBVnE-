# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Mục đích` | category | - | - | - | Phân loại chi tiêu theo mục đích chuyến đi (ví dụ: du lịch, thăm họ hàng) hoặc phương tiện di chuyển (ví dụ: máy bay, ô tô). |
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Ghi chú` | string | - | - | - | Ghi chú về tình trạng dữ liệu, ví dụ: 'Sơ bộ' cho dữ liệu chưa chính thức. |
| `Trị giá (Nghìn đồng)` | number | - | - | nghìn đồng | Chi tiêu bình quân của một lượt khách du lịch nội địa. |
