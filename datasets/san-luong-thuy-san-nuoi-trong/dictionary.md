# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Loại thủy sản` | category | - | - | - | Phân loại thủy sản nuôi trồng, bao gồm tổng số, cá và tôm. |
| `Ghi chú` | string | - | - | - | Ghi chú bổ sung cho dữ liệu, ví dụ: dữ liệu sơ bộ. |
| `Sản lượng (Nghìn tấn)` | number | , | . | nghìn tấn | Tổng sản lượng thủy sản nuôi trồng trong năm, tính bằng nghìn tấn. |
| `Chỉ số phát triển (Năm trước = 100) (%)` | number | , | . | % | Chỉ số phát triển sản lượng thủy sản nuôi trồng so với năm trước đó (năm trước được lấy làm 100%). |
