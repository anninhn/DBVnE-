# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `chỉ số phát triển, Năm` | category | - | - | - | Phân loại thủy sản nuôi trồng được thống kê, bao gồm 'Tổng số', 'Cá' và 'Tôm'. |
| `Ghi chú` | string | - | - | - | Ghi chú bổ sung về dữ liệu, ví dụ 'Sơ bộ' cho dữ liệu chưa chính thức. |
| `Sản lượng (Nghìn tấn)` | number | , | . | nghìn tấn | Tổng sản lượng thủy sản nuôi trồng theo từng loại (Tổng số, Cá, Tôm) trong năm. |
| `Chỉ số phát triển (Năm trước = 100) (%)` | number | , | . | % | Chỉ số phát triển sản lượng thủy sản nuôi trồng so với năm trước đó (lấy năm trước làm 100%). |
