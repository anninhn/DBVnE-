# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Tỉnh, thành phố` | category | - | - | - | Tên tỉnh, thành phố, vùng kinh tế hoặc tổng "CẢ NƯỚC" mà dữ liệu sản lượng lúa được thống kê. |
| `Năm` | number | - | - | năm | Năm thu hoạch vụ lúa đông xuân. Dữ liệu từ 1995 đến 2024. |
| `Ghi chú` | string | - | - | - | Ghi chú bổ sung cho dữ liệu, ví dụ "Sơ bộ". Các giá trị rỗng có thể hiểu là không có ghi chú đặc biệt. |
| `Sản lượng lúa đông xuân` | number | , | . | unknown | Tổng sản lượng lúa thu hoạch trong vụ đông xuân của địa phương/vùng/cả nước. |
