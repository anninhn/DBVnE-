| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Nguồn cung` | category | - | - | - | Loại nguồn cung cấp hoặc sử dụng năng lượng, ví dụ: khai thác, nhập khẩu, xuất khẩu, chuyển đổi. |
