# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Nguồn cung, tiêu thụ` | category | - | - | - | Các hoạt động liên quan đến cung cấp và tiêu thụ năng lượng, bao gồm khai thác, sản xuất, nhập khẩu, xuất khẩu, chuyển đổi và tiêu thụ cuối cùng. |
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Các nguồn năng lượng` | category | - | - | - | Loại năng lượng được thống kê (ví dụ: than, dầu thô, khí thiên nhiên, điện). |
| `Ghi chú` | string | - | - | - | Các ký hiệu ghi chú hoặc chú thích cho dữ liệu, thường là '(*)' hoặc để trống. |
| `Bảng cân đối năng lượng Việt Nam` | number | - | - | unknown | Giá trị cân đối năng lượng cho từng nguồn và hoạt động cung/tiêu thụ, có thể là giá trị âm (thâm hụt) hoặc dương (thặng dư). |
