# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Cách tính` | category | - | - | - | Loại chỉ tiêu thống kê dân số: tổng số dân (Nghìn người), tỷ lệ tăng trưởng (%) hoặc cơ cấu dân số (%). |
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu dân số. |
| `Ghi chú` | string | - | - | - | Ghi chú bổ sung về dữ liệu, ví dụ 'Sơ bộ' cho dữ liệu chưa chính thức. |
| `Tổng số` | number | - | - | Nghìn người | % | Tổng dân số trung bình của cả nước. Đơn vị phụ thuộc vào giá trị của cột 'Cách tính'. |
| `Nam` | number | - | - | Nghìn người | % | Dân số trung bình là nam giới. Đơn vị phụ thuộc vào giá trị của cột 'Cách tính'. |
| `Nữ` | number | - | - | Nghìn người | % | Dân số trung bình là nữ giới. Đơn vị phụ thuộc vào giá trị của cột 'Cách tính'. |
| `Thành thị` | number | - | - | Nghìn người | % | Dân số trung bình sống ở khu vực thành thị. Đơn vị phụ thuộc vào giá trị của cột 'Cách tính'. |
| `Nông thôn` | number | - | - | Nghìn người | % | Dân số trung bình sống ở khu vực nông thôn. Đơn vị phụ thuộc vào giá trị của cột 'Cách tính'. |
