# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu dân số. |
| `Phân tổ` | category | - | - | - | Tiêu chí phân loại dân số, bao gồm 'Tổng số', 'Nam', 'Nữ', 'Thành thị' và 'Nông thôn'. |
| `Ghi chú` | string | - | - | - | Ghi chú về tính chất của dữ liệu, ví dụ 'Sơ bộ' cho dữ liệu chưa chính thức. |
| `Tổng số (Nghìn người)` | number | , | . | nghìn người | Tổng số dân trung bình trong năm, tính bằng nghìn người. |
| `Tỷ lệ tăng (%)` | number | , | . | % | Tỷ lệ tăng dân số trung bình hàng năm, tính bằng phần trăm. |
| `Cơ cấu (%)` | number | , | . | % | Tỷ lệ cơ cấu của từng phân tổ dân số so với tổng số, tính bằng phần trăm. |
