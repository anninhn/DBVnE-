# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Loại` | category | - | - | - | Các thành phần cấu thành việc sử dụng Tổng sản phẩm trong nước (GDP) như tiêu dùng cuối cùng, tích lũy tài sản, chênh lệch xuất nhập khẩu. |
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Ghi chú` | string | - | - | - | Thông tin bổ sung về tính chất của dữ liệu, ví dụ 'Sơ bộ' cho biết dữ liệu chưa phải là cuối cùng. |
| `Giá trị (Tỷ đồng)` | number | , | . | tỷ VND | Giá trị tuyệt đối của từng thành phần sử dụng GDP, tính theo giá so sánh năm 2010. |
| `Chỉ số phát triển (Năm trước = 100) (%)` | number | , | . | % | Chỉ số thể hiện tốc độ tăng trưởng của từng thành phần sử dụng GDP so với năm liền kề trước đó. |
