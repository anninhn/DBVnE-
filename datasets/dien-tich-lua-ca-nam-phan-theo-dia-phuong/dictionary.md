# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Tỉnh, thành phố` | category | - | - | - | Tên tỉnh, thành phố hoặc vùng kinh tế. Bao gồm cả dữ liệu tổng hợp cho 'CẢ NƯỚC' và các vùng. |
| `Năm` | number | - | - | năm | Năm thống kê diện tích lúa. |
| `Ghi chú` | string | - | - | - | Thông tin bổ sung về dữ liệu, ví dụ 'Sơ bộ' cho biết dữ liệu chưa phải là số liệu chính thức cuối cùng. |
| `Diện tích lúa cả năm` | number | , | . | nghìn ha | Tổng diện tích gieo trồng lúa trong cả năm của địa phương hoặc vùng, tính bằng nghìn héc-ta. |
