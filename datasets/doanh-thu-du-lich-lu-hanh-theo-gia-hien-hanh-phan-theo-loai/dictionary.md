# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `cơ cấu, Thành phần kinh tế` | category | - | - | - | Phân loại các thành phần kinh tế tham gia vào hoạt động du lịch lữ hành, bao gồm tổng số, kinh tế nhà nước, ngoài nhà nước, tập thể, tư nhân, cá thể và khu vực có vốn đầu tư nước ngoài. |
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Ghi chú` | string | - | - | - | Ghi chú về tính chất của dữ liệu. Hầu hết các giá trị là trống, chỉ có một số ít ghi 'Sơ bộ'. |
| `Doanh thu (Tỷ đồng )` | number | - | - | tỷ VND | Tổng doanh thu từ hoạt động du lịch lữ hành theo giá hiện hành, tính bằng tỷ đồng. |
| `Cơ cấu (%)` | number | - | - | % | Tỷ lệ phần trăm doanh thu của từng thành phần kinh tế so với tổng doanh thu du lịch lữ hành. |
