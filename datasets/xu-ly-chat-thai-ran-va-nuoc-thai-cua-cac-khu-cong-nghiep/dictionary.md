# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Vùng, Loại khu công nghiệp` | category | - | - | - | Vùng địa lý được thống kê dữ liệu (ví dụ: Cả nước, Đồng bằng sông Hồng). |
| `Số khu công nghiệp` | category | - | - | - | Phân loại dữ liệu theo tổng số khu công nghiệp hoặc từng loại hình khu công nghiệp cụ thể (ví dụ: Khu công nghiệp, Khu chế xuất). |
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Tổng số khu công nghiệp (Khu)` | number | - | - | khu | Tổng số khu công nghiệp được thống kê trong vùng và loại hình tương ứng. |
| `Số khu công nghiệp xử lý đạt tiêu chuẩn quy định (Khu)` | number | - | - | khu | Số lượng khu công nghiệp có hệ thống xử lý chất thải đạt tiêu chuẩn quy định. |
| `Tỷ lệ khu công nghiệp xử lý đạt tiêu chuẩn quy định (%)` | number | - | - | % | Tỷ lệ phần trăm các khu công nghiệp có hệ thống xử lý chất thải đạt tiêu chuẩn quy định so với tổng số khu công nghiệp. |
