# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Vùng` | category | - | - | - | Vùng địa lý hoặc phạm vi tổng hợp (Cả nước) được thống kê, bao gồm 7 vùng kinh tế - xã hội của Việt Nam. |
| `Loại khu công nghiệp` | category | - | - | - | Phân loại các loại hình khu công nghiệp, bao gồm Khu công nghiệp, Khu chế xuất, Khu kinh tế, Khu công nghệ cao và tổng hợp (TỔNG SỐ). |
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu, từ 2015 đến 2017. |
| `Tổng số khu công nghiệp (Khu)` | number | - | - | khu | Tổng số khu công nghiệp hiện có trong vùng và loại tương ứng. |
| `Số khu công nghiệp xử lý đạt tiêu chuẩn quy định (Khu)` | number | - | - | khu | Số lượng khu công nghiệp có hệ thống xử lý chất thải (rắn và nước thải) đạt tiêu chuẩn theo quy định hiện hành. |
| `Tỷ lệ khu công nghiệp xử lý đạt tiêu chuẩn quy định (%)` | number | - | - | % | Tỷ lệ phần trăm các khu công nghiệp có hệ thống xử lý chất thải đạt tiêu chuẩn quy định so với tổng số khu công nghiệp. |
