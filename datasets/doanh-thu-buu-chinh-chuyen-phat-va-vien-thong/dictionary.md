# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Ngành` | category | - | - | - | Tên ngành kinh tế được thống kê, bao gồm Tổng số, Bưu chính, chuyển phát và Viễn thông. |
| `Ghi chú` | string | - | - | - | Ghi chú bổ sung về dữ liệu, ví dụ: 'Sơ bộ' cho dữ liệu chưa chính thức. |
| `Doanh thu - Tỷ đồng` | number | , | . | tỷ VND | Tổng doanh thu của ngành trong năm, tính bằng tỷ đồng. |
| `Chỉ số phát triển (Năm trước =100) (%)` | number | , | . | % | Chỉ số phát triển doanh thu của ngành so với năm trước đó (năm trước = 100%). |
