# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Phân tổ` | category | - | - | - | Các loại hình phân tổ vốn đầu tư thực hiện toàn xã hội, bao gồm tổng số và các thành phần chi tiết như vốn xây dựng cơ bản, vốn mua sắm tài sản cố định, v.v. |
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Ghi chú` | string | - | - | - | Ghi chú về tính chất của dữ liệu, ví dụ: 'Sơ bộ' cho dữ liệu chưa chính thức. |
| `Vốn đầu tư thực hiện toàn xã hội` | number | - | - | tỷ VND | Tổng vốn đầu tư thực hiện toàn xã hội tính theo giá hiện hành. |
