# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `scope` | category | - | - | - | Phạm vi dữ liệu: 'province' cho cấp tỉnh, 'region' cho cấp vùng hoặc cả nước. |
| `province` | category | - | - | - | Tên tỉnh/thành phố trực thuộc trung ương. Giá trị rỗng khi dữ liệu ở cấp vùng hoặc cả nước. |
| `region` | category | - | - | - | Tên vùng địa lý hoặc 'CẢ NƯỚC'. Giá trị rỗng khi dữ liệu ở cấp tỉnh. |
| `year` | number | - | - | năm | Năm thống kê dữ liệu. |
| `total_forest_area_nghin_ha` | number | - | - | nghìn ha | Tổng diện tích rừng. |
| `natural_forest_nghin_ha` | number | - | - | nghìn ha | Diện tích rừng tự nhiên. |
| `planted_forest_nghin_ha` | number | - | - | nghìn ha | Diện tích rừng trồng. |
| `new_planting_nghin_ha` | number | - | - | nghìn ha | Diện tích rừng trồng mới trong năm. |
| `forest_cover_pct` | number | - | - | % | Tỷ lệ che phủ rừng. |
| `flag` | string | - | - | - | Cột trống, không chứa dữ liệu. |
