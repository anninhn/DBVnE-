# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Tỉnh/Thành phố` | category | - | - | - | Tên đơn vị hành chính (tỉnh, thành phố trực thuộc trung ương) hoặc vùng kinh tế - xã hội. Bao gồm cả tổng số liệu cho 'CẢ NƯỚC'. |
| `Năm` | number | - | - | năm | Năm thống kê số liệu. |
| `Ghi chú` | category | - | - | - | Ghi chú về tính chất của số liệu, ví dụ 'Sơ bộ' cho dữ liệu chưa chính thức. |
| `Số lao động có việc làm trong nền kinh tế` | number | - | - | nghìn người | Tổng số lao động đang có việc làm trong nền kinh tế quốc dân. |
