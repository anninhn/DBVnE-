# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Loại chi` | category | - | - | - | Phân loại các khoản chi của ngân sách nhà nước, bao gồm tổng chi và các khoản chi cụ thể như chi đầu tư phát triển, chi sự nghiệp kinh tế - xã hội, giáo dục, y tế, v.v. |
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu chi ngân sách. |
| `Ghi chú` | string | - | - | - | Ghi chú về dữ liệu, ví dụ 'Ước tính' cho các số liệu chưa chính thức. |
| `Giá trị (Tỷ đồng)` | number | , | . | tỷ VND | Tổng giá trị chi ngân sách nhà nước theo từng loại chi trong năm, tính bằng tỷ đồng. |
| `Cơ cấu (%)` | number | , | . | % | Tỷ lệ phần trăm của từng loại chi so với tổng chi ngân sách nhà nước trong năm. |
