# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Phân tổ` | category | - | - | - | Các chỉ số phân loại về trật tự và an toàn xã hội. Đơn vị của giá trị tương ứng được ghi trong dấu ngoặc đơn của từng phân tổ (ví dụ: 'Vụ', 'Người', 'Tỷ đồng'). |
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Ghi chú` | string | - | - | - | Ghi chú về tính chất của dữ liệu, ví dụ: 'Sơ bộ' cho dữ liệu chưa chính thức. |
| `Trật tự và an toàn xã hội` | number | , | . | Xem cột 'Phân tổ' | Giá trị thống kê tương ứng với từng phân tổ và năm cụ thể. Đơn vị của giá trị này được xác định bởi phân tổ tương ứng trong cột 'Phân tổ'. |
