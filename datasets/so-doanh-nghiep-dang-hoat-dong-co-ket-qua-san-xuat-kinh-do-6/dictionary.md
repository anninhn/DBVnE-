# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Loại hình doanh nghiệp` | category | - | - | - | Phân loại doanh nghiệp theo loại hình sở hữu hoặc pháp lý (ví dụ: Doanh nghiệp Nhà nước, Doanh nghiệp ngoài Nhà nước, Doanh nghiệp có vốn đầu tư nước ngoài). |
