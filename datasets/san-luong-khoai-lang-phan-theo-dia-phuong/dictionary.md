# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Tỉnh, thành phố` | category | - | - | - | Tên tỉnh, thành phố hoặc vùng địa lý (ví dụ: Đồng bằng sông Hồng, CẢ NƯỚC) mà sản lượng khoai lang được thống kê. |
| `Năm` | number | - | - | năm | Năm thống kê sản lượng khoai lang. |
| `Ghi chú` | string | - | - | - | Ghi chú về dữ liệu, ví dụ 'Sơ bộ' cho biết dữ liệu chưa phải là cuối cùng. |
| `Sản lượng khoai lang` | number | , | . | unknown | Tổng sản lượng khoai lang thu hoạch được trong năm tại địa phương tương ứng. |
