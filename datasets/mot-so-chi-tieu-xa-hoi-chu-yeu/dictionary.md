# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Chỉ tiêu` | category | - | - | - | Tên của các chỉ tiêu xã hội được thống kê, ví dụ: Dân số trung bình, Tuổi thọ trung bình, Thu nhập bình quân đầu người, Tỷ lệ hộ nghèo. Đơn vị của chỉ tiêu thường được ghi kèm trong tên. |
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu cho từng chỉ tiêu. |
| `Ghi chú` | string | - | - | - | Ghi chú bổ sung về dữ liệu, ví dụ 'Sơ bộ' cho biết dữ liệu chưa phải cuối cùng. |
| `Một số chỉ tiêu xã hội chủ yếu` | number | - | - | unknown | Giá trị số liệu của chỉ tiêu xã hội tương ứng với từng năm. Đơn vị của giá trị này phụ thuộc vào chỉ tiêu cụ thể được ghi trong cột 'Chỉ tiêu'. |
