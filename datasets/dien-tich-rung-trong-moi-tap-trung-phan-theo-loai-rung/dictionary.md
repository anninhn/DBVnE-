# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Loại rừng` | category | - | - | - | Phân loại rừng theo mục đích sử dụng: tổng số, rừng sản xuất, rừng phòng hộ, rừng đặc dụng. |
| `Ghi chú` | string | - | - | - | Ghi chú về tình trạng dữ liệu, ví dụ 'Sơ bộ' cho biết dữ liệu chưa phải là số liệu chính thức. |
| `Diện tích (Nghìn ha)` | number | , | . | nghìn ha | Tổng diện tích rừng trồng mới tập trung theo từng loại rừng. |
| `Chỉ số phát triển (Năm trước =100) (%)` | number | , | . | % | Chỉ số phát triển diện tích rừng trồng mới tập trung so với năm trước đó (lấy năm trước làm gốc 100%). |
