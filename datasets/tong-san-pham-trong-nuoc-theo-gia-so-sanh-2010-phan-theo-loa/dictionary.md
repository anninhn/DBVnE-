# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Chỉ tiêu` | category | - | - | - | Các chỉ tiêu phân loại Tổng sản phẩm trong nước (GDP) theo thành phần kinh tế (Nhà nước, ngoài Nhà nước, FDI) hoặc theo ngành kinh tế (nông nghiệp, công nghiệp, dịch vụ). |
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Ghi chú` | string | - | - | - | Ghi chú về trạng thái của dữ liệu, ví dụ 'Sơ bộ' cho dữ liệu chưa chính thức. |
| `Giá trị (Tỷ đồng)` | number | , | . | tỷ VND | Giá trị Tổng sản phẩm trong nước (GDP) tính theo giá so sánh năm 2010, đơn vị tỷ đồng. |
| `Chỉ số phát triển (%)` | number | , | . | % | Chỉ số phát triển GDP (%) so với cùng kỳ năm trước. |
