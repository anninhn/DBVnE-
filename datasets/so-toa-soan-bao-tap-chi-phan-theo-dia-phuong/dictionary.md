# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Địa phương` | category | - | - | - | Tên địa phương (tỉnh/thành phố trực thuộc trung ương) hoặc vùng kinh tế, bao gồm cả tổng số toàn quốc. |
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Ghi chú` | category | - | - | - | Ghi chú về trạng thái dữ liệu, ví dụ: 'Sơ bộ' (dữ liệu chưa chính thức). |
| `Số tòa soạn báo, tạp chí` | number | - | - | tòa soạn | Tổng số tòa soạn báo và tạp chí hoạt động trong năm tại địa phương tương ứng. |
