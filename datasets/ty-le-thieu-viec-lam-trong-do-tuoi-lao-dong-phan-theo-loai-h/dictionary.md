# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Thành phần kinh tế` | category | - | - | - | Phân loại các thành phần kinh tế, bao gồm Tổng số, Kinh tế Nhà nước, Kinh tế ngoài Nhà nước và Khu vực có vốn đầu tư nước ngoài. |
| `Ghi chú` | string | - | - | - | Ghi chú về trạng thái dữ liệu (ví dụ: 'Sơ bộ' cho các số liệu chưa chính thức). Cột này chủ yếu trống. |
| `Tổng số (%)` | number | - | - | % | Tỷ lệ thiếu việc làm trong tổng số lực lượng lao động trong độ tuổi. |
