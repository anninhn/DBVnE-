# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Năm` | number | - | - | năm | Năm mà dữ liệu chỉ số giá vàng được ghi nhận. |
| `Vùng` | category | - | - | - | Vùng địa lý hoặc chỉ số chung của cả nước mà chỉ số giá vàng được tính toán. |
| `Tháng` | number | - | - | tháng | Tháng mà dữ liệu chỉ số giá vàng được ghi nhận. |
| `Chỉ số giá vàng` | number | , | . | % | Chỉ số giá vàng của tháng hiện tại so với tháng trước đó. Giá trị 100% thể hiện giá không đổi, lớn hơn 100% là tăng và nhỏ hơn 100% là giảm. |
