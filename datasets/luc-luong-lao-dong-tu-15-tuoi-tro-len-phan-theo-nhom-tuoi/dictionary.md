# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Nhóm tuổi` | category | - | - | - | Phân loại lực lượng lao động theo các nhóm tuổi khác nhau. |
| `Ghi chú` | string | - | - | - | Ghi chú bổ sung cho dữ liệu, ví dụ: 'Sơ bộ'. |
| `Tổng số (Nghìn người)` | number | , | . | nghìn người | Tổng số người trong lực lượng lao động theo nhóm tuổi, tính bằng nghìn người. |
| `Cơ cấu (%)` | number | , | . | % | Tỷ lệ phần trăm cơ cấu của lực lượng lao động theo nhóm tuổi so với tổng số. |
