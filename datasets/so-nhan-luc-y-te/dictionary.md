# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Cán bộ` | category | - | - | - | Loại hình cán bộ y tế hoặc dược sĩ được thống kê. |
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Ghi chú` | string | - | - | - | Ghi chú về dữ liệu, ví dụ: 'Sơ bộ' cho dữ liệu chưa chính thức. |
| `Tổng số - Nghìn Người` | number | , | . | nghìn người | Tổng số lượng cán bộ theo từng loại hình, tính bằng nghìn người. |
| `Chỉ số phát triển (Năm trước = 100) (%)` | number | , | . | % | Chỉ số phát triển của số lượng cán bộ so với năm trước đó (năm trước được lấy làm 100%). |
