# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Tỉnh/Thành phố` | category | - | - | - | Tên tỉnh, thành phố, vùng địa lý (ví dụ: Đồng bằng sông Hồng) hoặc toàn quốc ('CẢ NƯỚC') được thống kê. |
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Ghi chú` | string | - | - | - | Ghi chú về trạng thái của dữ liệu, ví dụ 'Sơ bộ' cho biết dữ liệu chưa chính thức. Cột này có nhiều giá trị trống. |
| `Tỷ suất chết của trẻ em dưới năm tuổi` | number | , | . | phần nghìn | Tỷ lệ trẻ em tử vong trước 5 tuổi, tính trên 1000 trẻ sinh sống. |
