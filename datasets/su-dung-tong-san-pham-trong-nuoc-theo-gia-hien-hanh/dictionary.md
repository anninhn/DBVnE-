# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Loại` | category | - | - | - | Các thành phần sử dụng Tổng sản phẩm trong nước (GDP) như tiêu dùng cuối cùng, tích lũy tài sản, chênh lệch xuất nhập khẩu. |
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Ghi chú` | string | - | - | - | Ghi chú về tính chất của dữ liệu. Giá trị 'Sơ bộ' cho biết dữ liệu chưa chính thức, nhiều dòng để trống. |
| `Giá trị (Tỷ đồng)` | number | , | . | tỷ VND | Giá trị tuyệt đối của từng thành phần sử dụng GDP, tính theo giá hiện hành. |
| `Cơ cấu (%)` | number | , | . | % | Tỷ trọng phần trăm của từng thành phần sử dụng GDP so với tổng số. |
