# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Loại thu` | category | - | - | - | Phân loại chi tiết các khoản thu của ngân sách nhà nước, bao gồm tổng thu, thu trong nước, thu từ dầu thô, thu từ xuất nhập khẩu, v.v. |
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu thu ngân sách nhà nước, từ 2000 đến 2024. |
| `Ghi chú` | string | - | - | - | Ghi chú bổ sung cho dữ liệu, ví dụ 'Ước tính' cho các số liệu dự kiến hoặc chưa chính thức. |
| `Giá trị (Tỷ đồng)` | number | , | . | tỷ VND | Giá trị thu ngân sách nhà nước theo từng loại thu trong năm, tính bằng tỷ đồng. |
| `Cơ cấu (%)` | number | , | . | % | Tỷ lệ phần trăm của từng loại thu so với tổng thu ngân sách nhà nước trong năm. |
