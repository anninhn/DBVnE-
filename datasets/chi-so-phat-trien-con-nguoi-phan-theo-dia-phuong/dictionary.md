# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Tỉnh/Thành phố` | category | - | - | - | Tên tỉnh/thành phố trực thuộc trung ương hoặc 'CẢ NƯỚC' cho số liệu tổng hợp toàn quốc. |
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Ghi chú` | string | - | - | - | Ghi chú về tình trạng dữ liệu, ví dụ 'Sơ bộ' cho các số liệu chưa chính thức hoặc đã được điều chỉnh. |
| `Chỉ số phát triển con người` | number | , | . | - | Giá trị Chỉ số Phát triển Con người (HDI), là một chỉ số tổng hợp đo lường mức độ phát triển của một quốc gia hoặc địa phương dựa trên ba khía cạnh cơ bản: sức khỏe (tuổi thọ), giáo dục (số năm học bình quân và số năm học kỳ vọng) và mức sống (thu nhập bình quân đầu người). |
