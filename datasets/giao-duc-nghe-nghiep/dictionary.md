# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Chỉ tiêu` | category | - | - | - | Tên các chỉ tiêu thống kê về giáo dục nghề nghiệp, ví dụ: số cơ sở, số giáo viên, số học sinh sinh viên tốt nghiệp, và các phân loại chi tiết. |
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Giáo dục nghề nghiệp` | number | , | . | unknown | Giá trị thống kê tương ứng với từng 'Chỉ tiêu'. Đơn vị của giá trị này thay đổi tùy thuộc vào chỉ tiêu cụ thể (ví dụ: 'Cơ sở' hoặc 'Nghìn người'). |
