# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Địa phương` | category | - | - | - | Tên địa phương, bao gồm cấp quốc gia (CẢ NƯỚC), các vùng kinh tế - xã hội và các tỉnh/thành phố trực thuộc trung ương. |
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Tổng số` | number | - | - | học sinh/giáo viên | Số học sinh phổ thông bình quân trên một giáo viên của tất cả các cấp học (tiểu học, trung học cơ sở, trung học phổ thông). |
| `Tiểu học` | number | - | - | học sinh/giáo viên | Số học sinh cấp tiểu học bình quân trên một giáo viên cấp tiểu học. |
| `Trung học cơ sở` | number | - | - | học sinh/giáo viên | Số học sinh cấp trung học cơ sở bình quân trên một giáo viên cấp trung học cơ sở. |
| `Trung học phổ thông` | number | - | - | học sinh/giáo viên | Số học sinh cấp trung học phổ thông bình quân trên một giáo viên cấp trung học phổ thông. |
