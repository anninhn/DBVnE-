# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Phân tổ` | category | - | - | - | Phân loại dữ liệu theo khu vực địa lý (Cả nước, Thành thị, Nông thôn) hoặc theo các vùng kinh tế-xã hội của Việt Nam. |
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu thu nhập. |
| `Ghi chú` | string | - | - | - | Thông tin ghi chú bổ sung về dữ liệu (ví dụ: Sơ bộ). |
| `Thu nhập bình quân đầu người một tháng` | number | - | - | unknown | Thu nhập bình quân của một người trong một tháng, tính theo giá hiện hành. |
