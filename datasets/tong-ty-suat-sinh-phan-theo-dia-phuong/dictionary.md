# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Địa phương` | category | - | - | - | Tên địa phương hoặc vùng địa lý (ví dụ: tỉnh, thành phố, vùng kinh tế, CẢ NƯỚC). |
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Ghi chú` | string | - | - | - | Ghi chú bổ sung về dữ liệu, ví dụ: 'Sơ bộ' cho dữ liệu chưa chính thức. |
| `Tổng tỷ suất sinh` | number | , | . | số con/phụ nữ | Tổng số con trung bình mà một phụ nữ có thể sinh trong suốt cuộc đời, nếu trải qua các tỷ suất sinh đặc trưng theo tuổi của một thời kỳ nhất định. |
