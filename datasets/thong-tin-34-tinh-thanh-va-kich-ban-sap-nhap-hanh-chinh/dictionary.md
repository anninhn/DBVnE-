# Dictionary

| Column | Type | Unit | Description |
|--------|------|------|-------------|
| `TinhThanh` | string | - | Tên tỉnh/thành phố. |
| `Truocsapnhap` | string | - | Liệt kê các tỉnh/thành phố được giả định sáp nhập vào một đơn vị hành chính mới. 'Không sáp nhập' nếu tỉnh thành đó không thuộc diện sáp nhập. |
| `Trungtamhanhchinhmoi` | string | - | Trung tâm hành chính mới được đề xuất cho đơn vị hành chính sau sáp nhập. |

| `SoDVHCcapxa` | number | đơn vị | Số lượng đơn vị hành chính cấp xã (xã, phường, thị trấn) của tỉnh/thành phố. |
| `GRDP` | number | unknown | Tổng sản phẩm trên địa bàn (GRDP) của tỉnh/thành phố. |
| `Thungansach` | number | unknown | Tổng thu ngân sách nhà nước trên địa bàn của tỉnh/thành phố. |
| `Socangbien` | number | cảng | Số lượng cảng biển hiện có trong tỉnh/thành phố. |
| `Sosanbay` | number | sân bay | Số lượng sân bay hiện có trong tỉnh/thành phố. |
| `Sapnhap` | boolean | - | Trạng thái sáp nhập của tỉnh/thành phố (1: thuộc diện sáp nhập, 0: không thuộc diện sáp nhập). |
| `ThuhangDanso` | number | hạng | Thứ hạng của tỉnh/thành phố về dân số so với các tỉnh thành khác trong dataset. |
| `ThuhangDientich` | number | hạng | Thứ hạng của tỉnh/thành phố về diện tích so với các tỉnh thành khác trong dataset. |
| `ThuhangGRDP` | number | hạng | Thứ hạng của tỉnh/thành phố về GRDP so với các tỉnh thành khác trong dataset. |
| `ThuhangThungansach` | number | hạng | Thứ hạng của tỉnh/thành phố về thu ngân sách so với các tỉnh thành khác trong dataset. |
