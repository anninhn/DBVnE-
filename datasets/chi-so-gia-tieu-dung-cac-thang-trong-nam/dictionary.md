# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Các tháng (tháng trước = 100)` | category | - | - | - | Tháng trong năm (ví dụ: Tháng 1, Tháng 2). Phần '(tháng trước = 100)' là mô tả cho cách tính chỉ số giá tiêu dùng, không phải tên cột. |
| `Năm` | number | - | - | năm | Năm thống kê chỉ số giá tiêu dùng. |
| `Chỉ số giá tiêu dùng các tháng trong năm` | number | , | . | % | Chỉ số giá tiêu dùng (CPI) của tháng hiện tại so với tháng trước đó (tháng trước = 100). Ví dụ: giá trị 103,80 nghĩa là giá tăng 3,80% so với tháng trước. |
