# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Khu vực` | category | - | - | - | Phân loại khu vực luân chuyển hàng hóa, bao gồm 'Tổng số', 'Trong nước' và 'Ngoài nước'. |
| `Ghi chú` | string | - | - | - | Ghi chú bổ sung cho dữ liệu, ví dụ 'Sơ bộ'. Cột này thường để trống. |
| `Khối lượng (Triệu tấn.km)` | number | , | . | triệu tấn.km | Tổng khối lượng hàng hóa luân chuyển, tính bằng triệu tấn.km. |
| `Chỉ số phát triển (Năm trước = 100) (%)` | number | , | . | % | Chỉ số phát triển của khối lượng hàng hóa luân chuyển so với năm trước đó (lấy năm trước làm 100%). Dữ liệu cho năm đầu tiên (1995) thường để trống. |
