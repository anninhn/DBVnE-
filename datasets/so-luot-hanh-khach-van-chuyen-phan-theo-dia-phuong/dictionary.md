# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Địa phương` | category | - | - | - | Tên địa phương hoặc vùng kinh tế (ví dụ: tỉnh, thành phố, vùng kinh tế) được thống kê. |

| `Ghi chú` | category | - | - | - | Thông tin ghi chú thêm về số liệu. Giá trị 'Sơ bộ' cho biết số liệu chưa chính thức. |
