# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Chia ra` | category | - | - | - | Phân loại đối tượng thống kê: Nữ giáo viên hoặc Học sinh nữ. |
| `Cấp học` | category | - | - | - | Cấp học của trường phổ thông: Tổng số, Tiểu học, Trung học cơ sở, Trung học phổ thông. |
| `Năm học` | string | - | - | năm học | Năm học thống kê dữ liệu (ví dụ: 2000-2001). |
| `Ghi chú` | string | - | - | - | Ghi chú bổ sung cho dữ liệu, ví dụ: 'Sơ bộ'. |
| `Số nữ giáo viên và học sinh` | number | , | . | nghìn người | Tổng số nữ giáo viên hoặc học sinh nữ theo từng cấp học và năm học. |
| `Chỉ số phát triển (Năm trước = 100)` | number | , | . | % | Chỉ số phát triển của số lượng nữ giáo viên hoặc học sinh nữ so với năm học trước (năm trước được lấy làm 100%). |
