# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `chỉ số phát triển, Phân loại` | category | - | - | - | Loại chỉ số thống kê được đo lường: số lớp, số giáo viên, hoặc số học sinh. |
| `Cấp học` | category | - | - | - | Cấp học phổ thông, bao gồm Tổng số, Tiểu học, Trung học cơ sở, và Trung học phổ thông. |
| `Năm học` | string | - | - | năm học | Khoảng thời gian của năm học, ví dụ '1995 -1996'. |
| `Ghi chú` | string | - | - | - | Các ghi chú bổ sung về dữ liệu, ví dụ 'Sơ bộ'. |
| `Số lớp, giáo viên và học sinh` | number | , | . | unknown | Giá trị số lượng lớp học, giáo viên hoặc học sinh tương ứng với chỉ số phân loại và cấp học. |
| `Chỉ số phát triển (Năm trước = 100) (%)` | number | , | . | % | Tốc độ tăng trưởng của chỉ số (số lớp, giáo viên hoặc học sinh) so với năm học trước, lấy năm trước làm 100%. |
