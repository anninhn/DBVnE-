# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Phân loại` | category | - | - | - | Loại đối tượng thống kê: Lớp học, Giáo viên hoặc Học sinh. |
| `Cấp học` | category | - | - | - | Cấp học phổ thông: Tổng số, Tiểu học, Trung học cơ sở, hoặc Trung học phổ thông. |
| `Năm học` | string | - | - | năm học | Năm học thống kê dữ liệu (ví dụ: 1995 - 1996). |
| `Ghi chú` | string | - | - | - | Ghi chú về dữ liệu, ví dụ 'Sơ bộ'. Cột này chủ yếu trống hoặc chứa ghi chú 'Sơ bộ'. |
| `Số lớp, giáo viên và học sinh` | number | , | . | nghìn đơn vị | Tổng số lượng lớp học, giáo viên hoặc học sinh tương ứng với 'Phân loại' và 'Cấp học' trong năm học đó. |
| `Chỉ số phát triển (Năm trước = 100) (%)` | number | , | . | % | Chỉ số phát triển của số liệu (số lớp, giáo viên hoặc học sinh) so với năm học trước, lấy năm trước làm 100%. |
