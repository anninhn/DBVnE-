# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Thành thị/nông thôn` | category | - | - | - | Phân loại theo khu vực địa lý: tổng số toàn quốc, khu vực thành thị hoặc khu vực nông thôn. |
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Ghi chú` | string | - | - | - | Ghi chú về dữ liệu, ví dụ: 'Sơ bộ' cho dữ liệu chưa chính thức. |
| `Tỷ suất sinh thô` | number | - | - | ‰ | Số trẻ em sinh ra sống trên 1.000 dân trong một năm. |
| `Tỷ suất chết thô` | number | - | - | ‰ | Số người chết trên 1.000 dân trong một năm. |
| `Tỷ lệ tăng tự nhiên` | number | - | - | ‰ | Mức độ tăng dân số tự nhiên, được tính bằng hiệu số giữa tỷ suất sinh thô và tỷ suất chết thô. |
