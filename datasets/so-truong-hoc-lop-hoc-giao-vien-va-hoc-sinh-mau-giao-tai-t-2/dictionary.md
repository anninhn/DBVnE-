# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Ðịa phương` | category | - | - | - | Tên địa phương hoặc vùng kinh tế hành chính được thống kê (bao gồm cả 'CẢ NƯỚC'). |
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Phân tổ` | category | - | - | unknown | Chỉ tiêu thống kê về giáo dục mầm non, bao gồm số trường học, số lớp học, số giáo viên và số học sinh. Đơn vị của chỉ tiêu được ghi trong dấu ngoặc đơn. |
| `Số trường học, lớp học, giáo viên và học sinh mẫu giáo tại thời điểm 30/9` | number | - | - | unknown | Giá trị thống kê của chỉ tiêu tương ứng tại cột 'Phân tổ', được ghi nhận vào thời điểm 30/9 hàng năm. Đơn vị cụ thể phụ thuộc vào giá trị của cột 'Phân tổ'. |
