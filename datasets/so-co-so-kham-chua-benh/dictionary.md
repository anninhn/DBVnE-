# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Loại cơ sở` | category | - | - | - | Phân loại các cơ sở khám chữa bệnh, bao gồm tổng số, bệnh viện, trạm y tế, và các cơ sở khác. |
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Cơ sở` | number | , | . | cơ sở | Tổng số lượng cơ sở khám chữa bệnh theo từng loại trong năm. |
| `Chỉ số phát triển (Năm trước = 100) (%)` | number | , | . | % | Chỉ số phát triển của số lượng cơ sở khám chữa bệnh so với năm trước đó (năm trước được lấy làm 100%). |
