# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `STT` | number | - | - | - | Số thứ tự của điểm ngập. |
| `Nguyên nhân` | category | - | - | - | Nguyên nhân chính gây ngập tại vị trí, bao gồm 'Ngập do mưa', 'Ngập do triều' hoặc 'Ngập do mưa và triều'. |
| `Mức độ` | category | - | - | - | Mức độ thường xuyên hoặc nghiêm trọng của tình trạng ngập, bao gồm 'Ngập thường xuyên', 'Ngập vừa', 'Ngập nhẹ'. |
| `Địa bàn` | string | - | - | - | Địa bàn hành chính (phường, quận) nơi điểm ngập tọa lạc. |
| `Vị trí ngập` | string | - | - | - | Tên đường hoặc mô tả cụ thể vị trí xảy ra ngập. |
