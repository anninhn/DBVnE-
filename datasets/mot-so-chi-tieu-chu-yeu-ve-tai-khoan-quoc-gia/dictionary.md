# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Chỉ tiêu` | category | - | - | - | Tên và đơn vị của các chỉ tiêu kinh tế vĩ mô về tài khoản quốc gia, ví dụ: Tổng sản phẩm trong nước, Tổng thu nhập quốc gia, Tích lũy tài sản. |
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu cho các chỉ tiêu. |
| `Ghi chú` | string | - | - | - | Ghi chú về tình trạng dữ liệu, ví dụ: 'Sơ bộ' cho dữ liệu ước tính ban đầu. |
| `Một số chỉ tiêu chủ yếu về tài khoản quốc gia` | number | - | - | unknown | Giá trị của chỉ tiêu tài khoản quốc gia tương ứng với từng năm. Đơn vị cụ thể được chỉ rõ trong cột 'Chỉ tiêu'. |
