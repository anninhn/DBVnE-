# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Mục đích` | category | - | - | - | Tiêu chí phân loại chi tiêu bình quân của khách du lịch nội địa, bao gồm tổng thể, theo giới tính (Nam/Nữ) và theo nghề nghiệp. |
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Ghi chú` | string | - | - | - | Thông tin bổ sung về trạng thái của dữ liệu, ví dụ 'Sơ bộ' cho biết dữ liệu chưa phải là số liệu chính thức cuối cùng. |
| `Trị giá (Nghìn đồng)` | number | , | . | nghìn đồng | Giá trị chi tiêu bình quân của một lượt khách du lịch nội địa. |
