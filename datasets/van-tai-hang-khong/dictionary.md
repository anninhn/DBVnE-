# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Hình thức` | category | - | - | - | Loại hình vận tải hàng không (ví dụ: vận chuyển hành khách, luân chuyển hàng hóa, trong nước, quốc tế) và đơn vị đo lường tương ứng. |
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Ghi chú` | string | - | - | - | Ghi chú bổ sung cho dữ liệu, ví dụ: 'Sơ bộ' cho các số liệu chưa chính thức. Hầu hết các giá trị là trống. |
| `Vận tải hàng không` | number | - | - | unknown | Giá trị thống kê của hoạt động vận tải hàng không. Đơn vị cụ thể được xác định bởi cột 'Hình thức'. |
