# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Tỉnh, thành phố` | category | - | - | - | Tên tỉnh, thành phố, vùng kinh tế hoặc tổng hợp 'CẢ NƯỚC' mà chỉ số sản xuất công nghiệp được thống kê. |
| `Năm` | number | - | - | năm | Năm thống kê chỉ số sản xuất công nghiệp. |
| `Ghi chú` | string | - | - | - | Ghi chú về loại số liệu, ví dụ 'Sơ bộ' cho dữ liệu chưa chính thức. |
| `Chỉ số sản xuất công nghiệp` | number | , | . | % | Chỉ số sản xuất công nghiệp (IIP) của địa phương hoặc cả nước, thường tính theo phần trăm so với cùng kỳ năm trước hoặc năm gốc. |
