# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Tỉnh, thành phố` | category | - | - | - | Tên tỉnh, thành phố hoặc vùng kinh tế. Bao gồm cả dữ liệu tổng hợp cho 'CẢ NƯỚC' và các vùng. |
| `Năm` | number | - | - | năm | Năm thu thập dữ liệu về diện tích thu hoạch thủy sản. |
| `Ghi chú` | string | - | - | - | Thông tin bổ sung về dữ liệu, ví dụ 'Sơ bộ' cho biết dữ liệu chưa phải cuối cùng. Có thể có giá trị rỗng. |
| `Diện tích thu hoạch thuỷ sản` | number | - | - | ha | Tổng diện tích mặt nước được sử dụng để nuôi trồng và thu hoạch thủy sản. |
