# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Phân loại` | category | - | - | - | Phân loại cơ sở khám chữa bệnh: 'Tổng số' bao gồm tất cả các loại hình cơ sở, 'Riêng bệnh viện' chỉ tính riêng số lượng bệnh viện. |
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Tổng số` | number | - | - | cơ sở | Tổng số cơ sở khám chữa bệnh được thống kê trong năm. |
| `Bộ Y tế quản lý` | number | - | - | cơ sở | Số lượng cơ sở khám chữa bệnh trực thuộc và do Bộ Y tế quản lý. |
| `Sở y tế quản lý` | number | - | - | cơ sở | Số lượng cơ sở khám chữa bệnh trực thuộc và do Sở Y tế các tỉnh/thành phố quản lý. |
| `Các ngành khác quản lý` | number | - | - | cơ sở | Số lượng cơ sở khám chữa bệnh do các bộ, ngành hoặc tổ chức khác (ngoài Bộ Y tế và Sở Y tế) quản lý. |
