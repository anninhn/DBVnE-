# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Mục đích` | category | - | - | - | Mục đích chi tiêu của khách quốc tế khi đến Việt Nam, bao gồm tổng chi tiêu bình quân và các hạng mục chi tiêu cụ thể. |
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu chi tiêu. |
| `Ghi chú` | string | - | - | - | Ghi chú về dữ liệu, ví dụ 'Sơ bộ' cho dữ liệu chưa chính thức hoặc có thể thay đổi. |
| `Trị giá (Đô la Mỹ)` | number | , | . | USD | Trị giá chi tiêu bình quân của khách quốc tế cho mục đích tương ứng, tính bằng Đô la Mỹ. |
| `Cơ cấu (%)` | number | , | . | % | Tỷ lệ phần trăm chi tiêu cho từng mục đích so với tổng chi tiêu bình quân của khách quốc tế. |
