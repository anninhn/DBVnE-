# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Tỉnh, thành phố` | category | - | - | - | Tên tỉnh, thành phố, vùng kinh tế hoặc tổng hợp 'CẢ NƯỚC' mà dữ liệu năng suất lúa được thống kê. |
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu năng suất gieo trồng lúa mùa. |
| `Ghi chú` | category | - | - | - | Ghi chú về tính chất của dữ liệu, ví dụ 'Sơ bộ' cho biết dữ liệu chưa phải là cuối cùng. Cột này có thể chứa giá trị rỗng. |
| `Năng suất gieo trồng lúa mùa` | number | - | - | tạ/ha | Năng suất gieo trồng lúa mùa, tính bằng tạ trên một hecta (1 tạ = 100 kg). |
