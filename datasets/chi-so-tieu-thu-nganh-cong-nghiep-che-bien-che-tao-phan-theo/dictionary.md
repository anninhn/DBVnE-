# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Ngành công nghiệp` | category | - | - | - | Tên các ngành công nghiệp chế biến, chế tạo, bao gồm cả tổng ngành 'TOÀN NGÀNH CHẾ BIẾN, CHẾ TẠO'. |
| `Năm` | number | - | - | năm | Năm thống kê chỉ số tiêu thụ của ngành công nghiệp. |
| `Ghi chú` | string | - | - | - | Ghi chú về tính chất của dữ liệu, ví dụ 'Sơ bộ' cho biết dữ liệu có thể chưa phải là cuối cùng. |
| `Chỉ số tiêu thụ ngành công nghiệp chế biến, chế tạo` | number | , | . | % | Chỉ số tiêu thụ của ngành công nghiệp chế biến, chế tạo, phản ánh mức độ tiêu thụ sản phẩm của ngành so với một kỳ gốc. |
