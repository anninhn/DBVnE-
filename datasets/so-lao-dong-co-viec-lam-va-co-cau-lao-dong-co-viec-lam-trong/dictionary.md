# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Ngành` | category | - | - | - | Tên ngành kinh tế hoặc tổng số lao động có việc làm. |
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Ghi chú` | string | - | - | - | Ghi chú về dữ liệu, ví dụ 'Sơ bộ' cho dữ liệu chưa chính thức. |
| `Tổng số (Nghìn người)` | number | , | . | nghìn người | Tổng số lao động có việc làm trong ngành kinh tế tương ứng. |
| `Cơ cấu (%)` | number | , | . | % | Tỷ lệ phần trăm lao động có việc làm của ngành so với tổng số lao động có việc làm. |
