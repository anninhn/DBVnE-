# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Khu vực kinh tế` | category | - | - | - | Phân loại các khu vực kinh tế bao gồm: Tổng số, Nông, lâm nghiệp và thủy sản, Công nghiệp - Xây dựng, và Dịch vụ. |
| `Ghi chú` | string | - | - | - | Ghi chú bổ sung cho dữ liệu, ví dụ 'Sơ bộ' cho các số liệu chưa chính thức. |
| `Tổng số (%)` | number | , | . | % | Tỷ lệ lao động có việc làm phi chính thức trong tổng số lao động của khu vực kinh tế tương ứng. |
