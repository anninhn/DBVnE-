# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Khu vực kinh tế` | category | - | - | - | Phân loại khu vực kinh tế bao gồm: Tổng số, Nông, lâm nghiệp và thủy sản, Công nghiệp - Xây dựng, và Dịch vụ. |
| `Ghi chú` | string | - | - | - | Ghi chú về tính chất của dữ liệu, ví dụ 'Sơ bộ' cho biết dữ liệu chưa chính thức. |
| `Tổng số (%)` | number | - | - | % | Tỷ lệ thiếu việc làm trong độ tuổi lao động của khu vực kinh tế tương ứng. |
