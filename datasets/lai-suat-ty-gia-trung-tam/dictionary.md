# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Chỉ tiêu` | category | - | - | - | Tên chỉ tiêu kinh tế, bao gồm các loại lãi suất tiền gửi bình quân (VND, USD theo kỳ hạn) và tỷ giá trung tâm. |
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Ghi chú` | string | - | - | - | Ghi chú bổ sung cho dữ liệu, ví dụ 'Sơ bộ'. Cột này có nhiều giá trị trống. |
| `Lãi suất, tỷ giá trung tâm` | number | , | . | unknown | Giá trị của chỉ tiêu kinh tế tương ứng. Đơn vị là phần trăm (%) đối với lãi suất và VND/USD đối với tỷ giá. |
