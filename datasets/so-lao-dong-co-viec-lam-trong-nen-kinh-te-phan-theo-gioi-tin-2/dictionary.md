# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Phân tổ` | category | - | - | - | Tiêu chí phân loại lao động có việc làm (Tổng số, Nam, Nữ, Thành thị, Nông thôn). |
| `Ghi chú` | string | - | - | - | Ghi chú về tính chất của dữ liệu (ví dụ: 'Sơ bộ' cho dữ liệu chưa chính thức). Hầu hết các giá trị đều trống. |
| `Tổng số - Nghìn người` | number | , | . | nghìn người | Tổng số lao động có việc làm trong nền kinh tế, tính bằng nghìn người. |
| `Tỷ lệ so với dân số (%)` | number | , | . | % | Tỷ lệ lao động có việc làm so với tổng dân số. |
