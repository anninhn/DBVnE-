# Dictionary

| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `Ngành` | category | - | - | - | Ngành vận tải hành khách, bao gồm Tổng số, Đường sắt, Đường bộ, Đường sông và Đường hàng không. |
| `Ghi chú` | string | - | - | - | Ghi chú về tình trạng dữ liệu, ví dụ 'Sơ bộ' cho các số liệu chưa chính thức. Hầu hết các dòng đều không có ghi chú. |
| `Lượt hành khách (Triệu lượt người)` | number | , | . | triệu lượt người | Tổng số lượt hành khách được vận chuyển trong năm, tính theo triệu lượt người. |
| `Chỉ số phát triển (Năm trước =100) (%)` | number | , | . | % | Chỉ số phát triển lượt hành khách vận chuyển so với năm trước đó (năm trước = 100%). |
