| Column | Type | Dec | Group | Unit | Description |
|--------|------|-----|-------|------|-------------|
| `Năm` | number | - | - | năm | Năm thống kê dữ liệu. |
| `chỉ số phát triển, Năm` | category | - | - | - | Loại hình vận tải hành khách (Tổng số, Đường sắt, Đường bộ, Đường sông, Đường hàng không). |
