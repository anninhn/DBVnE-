Hôm nay bạn muốn tìm hiểu gì?

Hỏi bằng tiếng Việt. Mình tìm dataset trong kho, bạn chọn, rồi harness phân tích ra góc bài.

Prototype có 3 kịch bản dựng sẵn: tìm thấy → thẻ đạt · tìm thấy → rào chắn loại · không tìm thấy → gợi ý góc khác.
